# Agataga

Start with [AGATAGA_CANONICAL.md](./AGATAGA_CANONICAL.md). It reconciles the existing build reference with the pre-build architecture draft and identifies decisions that block executable implementation.

The source Word documents in this folder are preserved unchanged. Phase 1 decisions are recorded in [docs/DECISIONS.md](./docs/DECISIONS.md); runtime work must stay within those approved boundaries.
