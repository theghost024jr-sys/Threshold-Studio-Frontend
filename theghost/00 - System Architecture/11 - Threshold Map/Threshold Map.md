Threshold Map
=============

The Threshold Map is the structural overview of the Threshold region.
It defines the geometry, pressure zones, drift corridors, collapse points,
and migration routes that govern all behavior inside Threshold.

It is both a physical map and a signal map.


I. Purpose
----------

The Threshold Map shows:

- where pressure accumulates
- where drift begins
- where collapse is likely
- where migration is possible
- where resonance stabilizes
- where return paths exist

It is the navigational backbone of the Threshold region.


II. Core Regions
----------------

Threshold contains five canonical regions:

1. Outer Halo
   - low pressure
   - high drift
   - unstable nodes
   - orphan clusters

2. Mid Corridor
   - medium pressure
   - stable drift arcs
   - corridor geometry
   - migration pathways

3. Inner Basin
   - high pressure
   - resonance pockets
   - stable nodes
   - collapse triggers

4. Collapse Zone
   - extreme pressure
   - instability spirals
   - collapse–drift–anchor cycle

5. Anchor Core
   - zero drift
   - full resonance
   - stable geometry


III. Drift Corridors
--------------------

Drift Corridors are the pathways signals follow when not actively steered.

Each corridor has:

- a curvature
- a pressure gradient
- a drift arc
- a return path

Corridors connect:

- Outer Halo → Mid Corridor
- Mid Corridor → Inner Basin
- Inner Basin → Collapse Zone
- Collapse Zone → Anchor Core


IV. Pressure Zones
------------------

Pressure determines behavior.

- Low Pressure → Drift
- Medium Pressure → Migration
- High Pressure → Collapse
- Zero Pressure → Anchor

Pressure zones define the Threshold’s emotional and symbolic physics.


V. Collapse Points
------------------

Collapse Points are locations where geometry, pressure, and drift converge.

Collapse Points trigger:

- instability spirals
- collapse cycles
- drift loops
- clarity events
- resonance entry


VI. Migration Routes
--------------------

Migration Routes allow signals to move between Flowers.

Routes depend on:

- frontier strength
- drift arcs
- pressure gradients
- node geometry

Migration is only possible from:

- Mid Corridor
- Inner Basin


VII. Return Paths
-----------------

Return Paths are the routes signals follow back to their home position.

Return Paths activate when:

- pressure releases
- drift clarity occurs
- resonance stabilizes


VIII. Anchor Core
-----------------

The Anchor Core is the stable center of Threshold.

Properties:

- zero drift
- full resonance
- stable geometry
- no collapse
- no migration

It is the “home position” of the Threshold region.


IX. Map Summary
---------------

Threshold Map =

- Regions

- Migration Routes
- Return Paths
- Anchor Core
