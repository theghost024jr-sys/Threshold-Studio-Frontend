Threshold Dynamic
=================

The Threshold Dynamic is the governing behavior of the Threshold region.
It defines how pressure, drift, collapse, resonance, and migration interact
to produce state changes inside Threshold.


I. Definition
-------------

The Threshold Dynamic is the continuous interaction of:

- Pressure
- Drift
- Collapse
- Resonance
- Migration
- Return

These six forces determine how Threshold behaves at every moment.

Pressure is the *driver* of Threshold behavior.

III. Threshold Dynamic Cycle
----------------------------

The Threshold Dynamic follows a repeating cycle:

1. Pressure rises  
2. Drift activates  
3. Instability forms  
4. Collapse triggers  
5. Resonance enters  
6. Return activates  
7. Pressure resets  

This cycle governs all Threshold behavior.


IV. Dynamic Zones
-----------------

Threshold contains four dynamic zones:

1. Halo Zone  
   - low pressure  
   - high drift  
   - unstable nodes  

2. Corridor Zone  
   - medium pressure  
   - stable drift arcs  
   - migration routes  

3. Basin Zone  
   - high pressure  
   - resonance pockets  
   - collapse triggers  

4. Core Zone  
   - zero drift  
   - full resonance  
   - stable geometry
