Purpose
The Environment Index is the canonical list of all environment nodes in the Threshold world.
It provides:
• 	a clean directory
• 	a navigational map
• 	a reference for canvases
• 	a stable anchor for environment expansion
• 	a single place to track all environment PNGs
This file prevents the Environment Layer from becoming cluttered and keeps the system scalable.

1. Environment Categories
Environments are grouped by their pressure archetype, not by biome.
This keeps the system aligned with physics rather than aesthetics.
