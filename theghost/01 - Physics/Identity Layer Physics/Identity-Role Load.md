**3. GATHERER LOAD — Accumulation**

_Adding load → alignment and density_

**Load Behavior:**

- load gathers inward
- pressure increases gradually
- distribution becomes denser

**Identity Effects:**

- boundaries strengthen
- drift converges
- resonance harmonizes

**Phase Bias:**  
Coherence, early Renewal

Gatherer load creates **identity density and alignment**.

**4. HOLDER LOAD — Compression**

_Concentrating load → rigidity and strain_

**Load Behavior:**

- load pools in narrow corridors
- pressure spikes
- strain rises

**Identity Effects:**

- boundaries harden
- drift linearizes
- resonance sharpens

**Phase Bias:**  
Tension

Holder load creates **identity bracing**.

**5. RELEASER LOAD — Release**

_Removing load → fragmentation and unbinding_

**Load Behavior:**

- load dissolves outward
- pressure drops unevenly
- residue forms

**Identity Effects:**

- boundaries dissolve
- drift bursts outward
- resonance diffuses

**Phase Bias:**  
Collapse

Releaser load creates **identity unbinding**.

**6. RESTORATIVE LOAD — Neutralization**

_Settling load → rest and emptiness_

**Load Behavior:**

- load sinks into low‑pressure basins
- pressure equalizes
- residue settles

**Identity Effects:**

- boundaries soften
- drift sinks
- resonance mutes

**Phase Bias:**  
Void

Restorative load creates **identity rest**.

**7. INITIATOR LOAD — Redistribution**

_Moving load upward → ignition and formation_

**Load Behavior:**

- load rises in spiral routes
- pressure warms
- distribution reorganizes

**Identity Effects:**

- boundaries reform
- drift spirals upward
- resonance brightens

**Phase Bias:**  
Renewal

Initiator load creates **identity formation**.

**8. HOW IDENTITY STRUCTURE SHAPES ROLE LOAD**

Identity modifies role load through:

**A. Boundaries**

- rigid boundaries → concentrate load
- soft boundaries → distribute load
- fractured boundaries → scatter load
- forming boundaries → channel load upward

**B. Weight**

- heavy identity → deeper load zones
- light identity → faster redistribution

**C. Flexibility**

- flexible identity → smooth load gradients
- inflexible identity → sharp load cliffs

**D. Fragmentation**

- fragmented identity → multiple fracture zones

**E. Memory**

- old load patterns reappear under pressure

Identity is the **pressure terrain** roles act upon.

**9. ROLE LOAD ACROSS THE FIVE PHASES**

Each role’s load behaves differently depending on the phase.

**A. In Coherence**

- Gatherer load expands
- Holder load softens
- Initiator load hums faintly

Pressure is **centered and stable**.

**B. In Tension**

- Holder load compresses
- Gatherer load narrows
- Releaser load begins to flicker

Pressure is **narrow and strained**.

**C. In Collapse**

- Releaser load fractures
- Holder load cracks
- Initiator load flickers erratically

Pressure is **unstable and bursting**.

**D. In Void**

- Restorative load settles
- Releaser load sinks
- Initiator load warms faintly

Pressure is **low and quiet**.

**E. In Renewal**

- Initiator load rises
- Gatherer load returns
- Restorative load stabilizes

Pressure is **rising and forming**.

**10. ROLE LOAD FEEDBACK LOOPS**

Load reinforces or destabilizes roles.

**Positive feedback:**

- accumulation → deeper Gatherer
- compression → deeper Holder
- release → deeper Releaser
- neutralization → deeper Restorative
- redistribution → deeper Initiator

**Negative feedback:**

- release reduces compression
- neutralization reduces release
- redistribution reduces neutralization
- accumulation reduces redistribution

Role load determines **role stability**.

**11. ROLE LOAD ANOMALIES**

When role load misfires:

**1. Accumulation Lock**

Gatherer load persists into Tension → stagnation.

**2. Compression Loop**

Holder load cycles without release → chronic strain.

**3. Release Cascade**

Releaser load multiplies → collapse storms.

**4. Deep Neutralization**

Restorative load dominates → void hollowing.

**5. Premature Redistribution**

Initiator load activates too early → fragile renewal.

Anomalies reveal **pressure–role imbalance**.
