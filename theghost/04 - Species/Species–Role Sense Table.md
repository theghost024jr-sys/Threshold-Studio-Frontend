00 Meta Systems — Species Architecture / Roles Layer
The Species–Role Sense Table defines how each Species archetype perceives, interprets, and responds to the Archetypal Roles.
It is the cross‑sensitivity matrix that reveals:
• 	which Roles a Species is attuned to
• 	which Roles a Species misreads
• 	which Roles a Species amplifies
• 	which Roles a Species is blind to
• 	which Roles trigger drift, distortion, or collapse
This table is the backbone of Species behavior, Role expression, and Signal interpretation across the Threshold world.

Purpose
This file establishes:
• 	the sensitivity levels (Low, Moderate, High, Critical)
• 	the interpretive tendencies of each Species
• 	the Role‑specific distortions each Species produces
• 	the Role‑specific gifts each Species can unlock
• 	the environmental influence on Species–Role interactions
It is the diagnostic map for understanding how identity, environment, and archetype interact.

Sensitivity Levels
These are the four canonical levels used across the table:
Low
• 	weak attunement
• 	minimal influence
• 	low distortion risk
• 	often blind to nuance
Moderate
• 	functional attunement
• 	stable interpretation
• 	predictable behavior
High
• 	strong attunement
• 	amplified interpretation
• 	increased drift potential
Critical
• 	overwhelming attunement
• 	volatile interpretation
• 	collapse or breakthrough conditions
• 	threshold events likely
These levels are consistent with the Species–Role Sensitivity Table you already built earlier.

Interpretive Behaviors
Each Species interprets Roles differently.
This section defines the behavioral logic behind the sensitivity levels.
Examples (generic, not species‑specific):
• 	High sensitivity to Guide → seeks direction, over‑interprets signals
• 	Critical sensitivity to Trickster → destabilizes, misreads intent
• 	Low sensitivity to Keeper → ignores boundaries, weak structure
• 	Moderate sensitivity to Maker → stable collaboration, predictable output
• 	High sensitivity to Witness → strong emotional resonance, memory activation
This section becomes the reference for all Species files.

Environmental Influence
Each Layer modifies Species–Role sensitivity:
• 	Air → increases clarity, reduces distortion
• 	Earth → increases weight, slows interpretation
• 	Ember → amplifies emotional resonance
• 	Mist → increases ambiguity and drift
• 	Stone → increases rigidity and fracture risk
• 	Ethyl → increases symbolic bleed‑through
This is where the table becomes dynamic instead of static.
