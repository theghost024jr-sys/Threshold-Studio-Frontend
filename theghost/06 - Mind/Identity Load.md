1. WHAT IDENTITY LOAD IS
Identity Load is the total pressure an identity carries at any moment.
It is composed of:
• 	Phase Load (pressure from the current Cycle phase)
• 	Role Load (pressure from active roles)
• 	Emotional Load (felt intensity, internal strain)
• 	Narrative Load (story weight, meaning density)
• 	Environmental Load (external pressure from surroundings)
• 	Memory Load (residual imprint from past phases)
• 	Collapse Residue Load (unresolved fragments)
Identity Load is the mass of selfhood.

2. THE FIVE COMPONENTS OF IDENTITY LOAD
Identity Load is not one thing — it is a composite.
A. Structural Load
The weight identity carries simply by existing.
Determined by identity weight, boundaries, and flexibility.
B. Phase Load
The pressure exerted by the current Cycle phase.
• 	Coherence → alignment pressure
• 	Tension → compression pressure
• 	Collapse → dissolution pressure
• 	Void → stillness pressure
• 	Renewal → ignition pressure
C. Role Load
Each role adds or removes load:
• 	Gatherer → accumulates
• 	Holder → compresses
• 	Releaser → removes
• 	Restorative → neutralizes
• 	Initiator → redistributes
D. Memory Load
The imprint of previous cycles.
• 	strong coherence memory → stabilizing
• 	strong collapse memory → destabilizing
• 	strong void memory → slowing
• 	strong renewal memory → accelerating
E. Residue Load
Unresolved fragments from collapse or tension.
Residue load is the heaviest form of load.

3. HOW LOAD MOVES THROUGH IDENTITY
Load is not static — it flows.
A. Load Accumulation
Load increases when:
• 	boundaries harden
• 	roles brace
• 	drift compresses
• 	resonance sharpens
• 	environment densifies
• 	memory resurfaces
B. Load Distribution
Load spreads across identity structure.
• 	flexible identities distribute load evenly
• 	rigid identities concentrate load
• 	fragmented identities scatter load
C. Load Release
Load decreases when:
• 	roles unbind
• 	drift scatters
• 	resonance diffuses
• 	identity softens
• 	environment rests
Load is the pressure metabolism of identity.

5. LOAD–IDENTITY FEEDBACK LOOPS
Identity and load reinforce each other.
Positive feedback (amplifying):
• 	high load → more rigidity → more load
• 	fragmentation → residue → more load
• 	sharp resonance → strain → more load
Negative feedback (balancing):
• 	collapse reduces tension load
• 	void reduces collapse load
• 	renewal reduces void load
Feedback loops determine identity stability.
