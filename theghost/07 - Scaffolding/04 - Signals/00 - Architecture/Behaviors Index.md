# Behaviors Index
*03 Signals — Behavioral Physics of Resonance Pairs*

1. Overview
Behavior in Threshold describes how each resonance pair acts, reacts, and distorts under different conditions.
Every pair has three modes:
• 	Stable behavior — aligned, functional expression
• 	Stress behavior — distortion under pressure
• 	Break behavior — collapse or inversion of the pattern
This index defines the behavioral physics of the entire system.

2. Mistreach ↔ Gate
Theme: Uncertainty, thresholds, first contact
Stable
• 	Curiosity
• 	Openness
• 	Testing boundaries
• 	Feeling for the edge
Stress
• 	Hesitation
• 	Fog
• 	False openings
• 	Misreading cues
Break
• 	Panic entry
• 	Premature commitment
• 	Falling into the wrong path

3. Airswell ↔ Signal
Theme: Pattern, motion, communication
Stable
• 	Clarity
• 	Momentum
• 	Clean transmission
• 	Recognizing patterns
Stress
• 	Noise
• 	Over‑interpretation
• 	Mixed messages
• 	Chasing false signals
Break
• 	Overload
• 	Signal collapse
• 	Misfire that triggers rupture

• 	Freezing
• 	Becoming immovable
