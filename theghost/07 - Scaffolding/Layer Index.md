Layer Ordering Logic
The layers are ordered by:
• 	subtle → dense
• 	motion → meaning → structure → ignition → distribution → emotion
• 	low‑pressure → high‑pressure
• 	low symbolic density → high symbolic density
This ordering is structural, not thematic.

Layer Relationships
Vertical Relationships
Each layer influences the one above and below it:
• 	Drift softens into Mist
• 	Mist refracts into Shimmer
• 	Shimmer stabilizes into Stone
• 	Stone ignites into Ember
• 	Ember distributes into Ethyl
• 	Ethyl intensifies into Heat
Cross‑Layer Interactions
Cross‑layer interactions occur when:
• 	Drift meets Shimmer → motion‑meaning arcs
• 	Mist meets Stone → soft‑structure gradients
• 	Ember meets Heat → ignition‑emotion spikes
• 	Ethyl meets Drift → distributed motion
These interactions are defined in Layer Physics Index.md.

Layer Identity Rules
A layer is defined by:
1. 	Field Behavior
2. 	Emotional Physics
3. 	Symbolic Density
4. 	Collapse Response
5. 	Environmental Expression
If an element does not express all five, it is not a layer.

# Layers Index

The Layer System defines the seven fundamental physics regimes of Threshold.  
Layers are not locations or realms.  
They are **domains of behavior** — each with its own pressure rules, resonance patterns, drift tendencies, and collapse interactions.

This index provides a unified reference for all Layer files and their cross‑system roles.
