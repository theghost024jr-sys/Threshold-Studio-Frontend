# Layers Index

The Layer System defines the seven fundamental physics regimes of Threshold.  
Layers are not locations or realms.  
They are **domains of behavior** — each with its own pressure rules, resonance patterns, drift tendencies, and collapse interactions.

This index provides a unified reference for all Layer files and their cross‑system roles.

---

## Purpose
- Maintain a canonical directory of all Layers  
- Define each Layer’s core physics and systemic function  
- Support navigation across the multi‑Layer map  
- Provide cross‑links to Layer Physics, Drift, and Substrate systems  
- Anchor the Layer stack within the overall architecture
