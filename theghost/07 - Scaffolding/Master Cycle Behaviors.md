Master Cycle Behaviors
Overview
Each phase of the Master Cycle expresses a distinct behavioral mode.
Every phase has three expressions:
• 	Stable — aligned, functional behavior
• 	Stress — distortion under pressure
• 	Break — collapse or inversion
These modes synchronize across all layers of Threshold:
zones → nodes → roles → triads → pathways → behaviors.

1. Gate — Initiation
Essence: Opening, curiosity, threshold contact
Stable
• 	Lightness
• 	Openness to possibility
• 	Gentle forward motion
• 	Testing edges without fear
Stress
• 	Hesitation
• 	Over‑scanning
• 	False openings
• 	Ambiguous signals
Break
• 	Premature leap
• 	Panic entry
• 	Grabbing the wrong path
• 	Threshold collapse

2. Signal — Patterning
Essence: Meaning, momentum, interpretation
Stable
• 	Clarity
• 	Clean pattern recognition
• 	Momentum building
• 	Information flow
Stress
• 	Noise
• 	Over‑interpretation
• 	Mixed messages
• 	Chasing false patterns
Break
• 	Overload
• 	Signal collapse
• 	Misfire that triggers rupture

3. Fault — Rupture
Essence: Breakpoint, release, volatility
Stable
• 	Necessary disruption
• 	Clean break
• 	Pressure release
• 	Transformation spark
Stress
• 	Escalation
• 	Sharp reactions
• 	Emotional spikes
• 	Instability
Break
• 	Explosive rupture
• 	Burnout
• 	System fracture
• 	Chain‑reaction breaks

4. Drift — Dissolution
Essence: Unmaking, surrender, loss of orientation
Stable
• 	Softening
• 	Letting go
• 	Depth
• 	Intuition
Stress
• 	Fog
• 	Dissociation
• 	Losing the thread
• 	Emotional diffusion
Break
• 	Total disorientation
• 	Falling out of the cycle
• 	Loss of self‑contact

5. Anchor — Grounding
Essence: Stability, presence, gravity
Stable
• 	Centering
• 	Contact
• 	Integration
• 	Calm gravity
Stress
• 	Rigidity
• 	Over‑control
• 	Defensive grounding
• 	Emotional bracing
Break
• 	Collapse of stability
• 	Losing the ground
• 	Falling into Drift or Fault

6. Return — Integration
Essence: Reassembly, renewal, coherence
Stable
• 	Synthesis
• 	Re‑alignment
• 	Clean re‑entry
• 	Completion
Stress
• 	Partial integration
• 	Looping
• 	Incomplete return
• 	Emotional whiplash
Break
• 	Failed return
• 	Re‑entry shock
• 	Falling back into Gate or Fault

7. Burden — Continuity
Essence: Weight, memory, structure
Stable
• 	Reliability
• 	Continuity
• 	Holding what matters
• 	Structural integrity
Stress
• 	Heaviness
• 	Over‑responsibility
• 	Drag
• 	Emotional inertia
Break
• 	Collapse under weight
• 	Freezing
• 	Becoming immovable
• 	Burden → Drift inversion

Behavioral Arc of the Master Cycle
Across all phases, the Master Cycle expresses a universal emotional pattern:
1. 	Opening
2. 	Meaning
3. 	Rupture
4. 	Dissolution
5. 	Grounding
6. 	Integration
7. 	Continuity
This arc repeats at every scale — moment, day, season, life.
