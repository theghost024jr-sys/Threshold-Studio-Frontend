The Master Cycle is the complete seven‑phase transformation loop that synchronizes every layer of Threshold:
• 	Outer Map (zones)
• 	Inner Engine (nodes)
• 	Roles
• 	Triads
• 	Behaviors
• 	Pathways
Each phase expresses a distinct mode of movement, pressure, and transformation.
All other cycles in the system are sub‑cycles of this one.

2. The Seven Phases of the Master Cycle
Phase 1 — Gate (Initiation)
Zone: Mistreach
Node: Gate
Role: Gate‑Opener
Triad: Initiation Engine
Behavior: Curiosity, openness, boundary‑testing
Movement: Stable → Drift
Function: A threshold opens; the cycle begins.

Phase 2 — Signal (Patterning)
Zone: Airswell
Node: Signal
Role: Signal‑Keeper
Triad: Initiation → Rupture
Behavior: Pattern recognition, momentum, clarity
Movement: Stable
Function: Meaning emerges; direction forms.

Phase 3 — Fault (Rupture)
Zone: Emberfall
Node: Fault
Role: Fault‑Bearer
Triad: Rupture Engine
Behavior: Volatility, escalation, breakpoints
Movement: Fault
Function: The system ruptures; pressure releases.

Phase 4 — Drift (Dissolution)
Zone: Ethyldeep
Node: Drift
Role: Drift‑Walker
Triad: Dissolution Engine
Behavior: Fog, surrender, disorientation
Movement: Drift
Function: Structure dissolves; orientation loosens.

Phase 5 — Anchor (Grounding)
Zone: Earthbind
Node: Anchor
Role: Anchor‑Holder
Triad: Grounding Engine
Behavior: Presence, stabilization, gravity
Movement: Stable
Function: Contact returns; the system regains center.

Phase 6 — Return (Integration)
Zone: Threshold (outer)
Node: Return
Role: Return‑Guide
Triad: Integration Engine
Behavior: Renewal, synthesis, re‑entry
Movement: Stable → Fault
Function: The system reassembles; meaning is integrated.

Phase 7 — Burden (Continuity)
Zone: Stonefield
Node: Burden
Role: Burden‑Carrier
Triad: Continuity Engine
Behavior: Weight, memory, structure
Movement: Stable
Function: What remains is carried forward.

3. Cycle Reset
Burden → Gate
The accumulated weight becomes the next threshold.
The cycle restarts.

5. Pathway Alignment
Each phase corresponds to a movement type:
• 	Stable: Signal, Anchor, Burden
• 	Drift: Gate, Drift
• 	Fault: Fault, Return
The Master Cycle is the only cycle that uses all three movement types in a fixed order.

7. 	Opening

13. 	Continuity
