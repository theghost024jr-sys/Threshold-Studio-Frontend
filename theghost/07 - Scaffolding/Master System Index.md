1. System Overview
Threshold is a dual‑layer architecture consisting of:
• 	The World Map (Outer Map) — environmental physics
• 	The Threshold Engine (Inner Map) — psychological/metaphysical cycle
• 	Cross‑Map Resonance — how outer zones mirror inner nodes
• 	Pathways — how movement between zones reflects inner transitions
• 	Behavioral Physics — how each resonance pair acts under pressure
• 	Roles (future layer) — archetypes that move through the system
This file is the top‑level index for all layers.

2. Layer Structure
Threshold is built from three primary layers:
Layer 1 — Outer Map (World Map)
Zones:
Stonefield, Mistreach, Airswell, Emberfall, Ethyldeep, Earthbind, Threshold (center)
Layer 2 — Inner Map (Threshold Engine)
Nodes:
Gate, Signal, Burden, Drift, Fault, Anchor, Return
Layer 3 — Cross‑Map Resonance
Each zone ↔ one node
This creates the “as above, so below” structure.
