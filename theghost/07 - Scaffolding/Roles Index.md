[[Signals]]

1. Overview
Roles are archetypal patterns that move through Threshold.
Each role expresses:
• 	a home zone (outer map)
• 	a home node (inner engine)
• 	a behavioral signature (stable, stress, break)
• 	a movement pattern (preferred pathways)
• 	a narrative arc (how the role transforms)
Roles are not characters — they are forces, stances, or modes of being.
This index defines the architecture of the roles layer.

2. Role Structure Template
Every role file follows the same structure for consistency and future‑proofing:
Essence
The core nature of the role.
Core Function
What the role does in the system.
Emotional Signature
How the role feels from the inside.
Strengths
Aligned expression.
Shadow
Distorted expression.
Drift Behavior
How the role loses orientation.
Collapse Behavior
How the role breaks.
Elemental Resonance
Optional symbolic layer.
Zone Alignment
Which world zone the role belongs to.
Node Alignment
Which inner node the role expresses.
Pathway Pattern
How the role moves through the system.
Mythic Resonance
The narrative or archetypal echo.
Links
• 	Home zone
• 	Home node
• 	Related roles
• 	Pathways Index
• 	Behaviors Index
This template ensures every role is structurally identical.
