# **THRESHOLD ENGINE v2 — SUBSYSTEM MAP**

This is the **canonical list** of every subsystem in Threshold Engine v2. Nothing else exists outside this map. Everything plugs into one of these layers.

# **0. SUBSTRATE LAYER (ROOT)**

The foundational layer that all other systems depend on.

- **0.1 Substrate Core** — global logic, global rules, engine invariants
    
- **0.2 Fib Flower Spine** — recursive structure, scaling, expansion pattern
    
- **0.3 State Manager** — world state, subsystem state, transitions
    
- **0.4 Interface Bus** — communication channels between subsystems
    

# **1. PHYSICS LAYER**

The rules of the world. Not “real physics” — Threshold physics.

- **1.1 Core Physics** — forces, motion, interaction rules
    
- **1.2 Drift Physics** — deviation, instability, environmental pressure
    
- **1.3 Collapse Physics** — failure modes, breakdown, thresholds
    
- **1.4 Stabilization Physics** — recovery, equilibrium, resilience
    

# **2. WORLD LAYER**

The environment as a living system.

- **2.1 Terrain Logic** — topology, zones, boundaries
    
- **2.2 Environmental Systems** — weather, cycles, conditions
    
- **2.3 Resource Logic** — scarcity, abundance, regeneration
    
- **2.4 World Events** — systemic changes, shifts, emergent phenomena
    

# **3. ORGANISM LAYER**

Everything that lives, moves, or acts inside the world.

- **3.1 Organism Core** — identity, state, lifecycle
    
- **3.2 Behavior Engine** — instincts, drives, reactions
    
- **3.3 Needs & Pressures** — hunger, safety, stability, alignment
    
- **3.4 Adaptation Logic** — growth, mutation, evolution
    

# **4. SPECIES LAYER**

The templates organisms derive from.

- **4.1 Species Definitions** — traits, capabilities, constraints
    
- **4.2 Species Variation** — subtypes, mutations, environmental forms
    
- **4.3 Species Interactions** — predator/prey, symbiosis, competition
    

# **5. MOTION LAYER**

How things move, navigate, and interact physically.

- **5.1 Locomotion** — walking, flying, swimming, climbing
    
- **5.2 Navigation** — pathfinding, avoidance, pursuit
    
- **5.3 Interaction Physics** — collisions, pushes, pulls, impacts
    

# **6. MIND LAYER**

The internal logic of agents (player or organism).

- **6.1 Perception** — sensing, awareness, detection
    
- **6.2 Interpretation** — meaning, threat assessment, opportunity
    
- **6.3 Decision Engine** — choices, priorities, action selection
    
- **6.4 Memory** — short‑term, long‑term, environmental imprint
    

# **7. SCAFFOLDING LAYER**

The systems that support world structure and gameplay loops.

- **7.1 Quest Logic** — tasks, goals, progression
    
- **7.2 Economy Logic** — value, exchange, cost
    
- **7.3 Social Logic** — factions, alliances, reputation
    
- **7.4 Narrative Scaffolding** — events, arcs, triggers (non‑authorial)
    

# **8. PLAYER LAYER**

The interface between the human and the world.

- **8.1 Player Agent** — avatar, stats, state
    
- **8.2 Player Input** — controls, actions, commands
    
- **8.3 Player Feedback** — UI, signals, world response
    

# **9. VIEWPORT LAYER**

The Godot‑side representation of the world.

- **9.1 Rendering** — visuals, lighting, effects
    
- **9.2 Scene Graph** — nodes, hierarchy, instancing
    
- **9.3 Interaction Layer** — collisions, triggers, sensors
    

# **10. TOOLING LAYER**

External tools that support development but do not define the system.

- **10.1 Blender Shapes** — models, meshes, assets
    
- **10.2 Excel Mechanics** — prototypes, formulas, simulations
    
- **10.3 Debug Tools** — inspectors, logs, visualizers
    

# **END OF MAP**

This is the **official subsystem map**. Everything in Threshold Engine v2 lives here. Nothing outside this list is allowed.
