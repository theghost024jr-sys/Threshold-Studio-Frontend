Overview
The Universal Interaction Engine defines the seven fundamental actions that any player or agent can take inside Threshold.
These actions are not verbs in a game‑design sense — they are forces that interact with the global system.
Every environment, role, triad, and phase responds to these seven interactions.
These are the only ways the world can be moved.

1. The Seven Universal Interactions
2. Approach
Moving toward something.
This activates Opening dynamics.
Effects:
• 	triggers Gate behavior
• 	increases orientation force
• 	begins phase transitions
• 	can destabilize False Gate

3. Attention
Focusing on something.
This activates Patterning dynamics.
Effects:
• 	strengthens Signal
• 	clarifies coherence
• 	stabilizes Noise Spiral
• 	reveals hidden triad structure

3. Pressure
Applying force — emotional, cognitive, physical.
This activates Breaking dynamics.
Effects:
• 	triggers Fault
• 	releases stored tension
• 	can escalate into Destructive Rupture
• 	tests structural integrity

4. Stillness
Withdrawing movement or pressure.
This activates Dissolution dynamics.
Effects:
• 	triggers Drift
• 	softens boundaries
• 	can collapse into Dissociation
• 	resets sensory channels

5. Grounding
Stabilizing, anchoring, connecting to weight.
This activates Gravity dynamics.
Effects:
• 	triggers Anchor
• 	restores stability
• 	prevents Rigidity
• 	re‑establishes contact

6. Synthesis
Combining, integrating, recombining meaning.
This activates Integration dynamics.
Effects:
• 	triggers Return
• 	reassembles coherence
• 	prevents Failed Re‑Entry
• 	completes loops

7. Memory
Holding, carrying, or referencing what came before.
This activates Continuity dynamics.
Effects:
• 	triggers Burden
• 	maintains identity
• 	prevents Immobilizing Weight
• 	enables long‑arc structure

8. Interaction → Phase Mapping

This is the core mapping of the entire system.

3. Interaction → Environment Behavior
Every environment responds to the seven interactions:
• 	Gate environments open when approached
• 	Signal environments reveal patterns under attention
• 	Fault environments break under pressure
• 	Drift environments dissolve under stillness
• 	Anchor environments stabilize under grounding
• 	Return environments recombine under synthesis
• 	Burden environments deepen under memory
Shadow environments respond with distortion.

4. Interaction → Collapse Logic
Collapse occurs when an interaction is:
• 	misapplied
• 	over‑applied
• 	under‑applied
• 	applied at the wrong phase
• 	applied in the wrong environment
• 	applied with the wrong role
Examples:
• 	Too much pressure → Destructive Rupture
• 	Too much stillness → Dissociation
• 	Too much grounding → Rigidity
• 	Too much memory → Immobilizing Weight
The Interaction Engine is the trigger for collapse.

5. Interaction → Recovery Logic
Recovery is also triggered by interaction:
• 	False Gate recovers through Attention
• 	Noise Spiral recovers through Pressure
• 	Destructive Rupture recovers through Stillness
• 	Dissociation recovers through Grounding
• 	Rigidity recovers through Synthesis
• 	Failed Re‑Entry recovers through Memory
• 	Immobilizing Weight recovers through Approach
This is the universal recovery engine.

6. Interaction → Role Activation
Each role is activated by a specific interaction:
• 	Gate‑Opener → Approach
• 	Signal‑Keeper → Attention
• 	Fault‑Bearer → Pressure
• 	Drift‑Walker → Stillness
• 	Anchor‑Holder → Grounding
• 	Return‑Weaver → Synthesis
• 	Burden‑Carrier → Memory
Roles are interaction archetypes.

7. Interaction → Triad Activation
Triads respond to combinations of interactions:
• 	Initiation Engine → Approach + Attention
• 	Rupture Engine → Pressure + Stillness
• 	Continuity Engine → Grounding + Memory
• 	Integration Engine → Synthesis + Memory
• 	Dissolution Engine → Stillness + Drift
• 	Pattern Engine → Attention + Signal
Triads are interaction patterns.

8. Purpose of the Interaction Engine
The Interaction Engine ensures:
• 	the world is responsive
• 	collapse is predictable
• 	recovery is actionable
• 	roles are meaningful
• 	triads are functional
• 	environments are alive
• 	cycles are interactive
It is the input layer of Threshold.
