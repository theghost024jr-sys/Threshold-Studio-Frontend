# **Migration Rules**

Migration governs how nodes escape their current Flower, elevate orbit layers, enter migration corridors, or become captured by another Flower. Migration is not random — it is the result of pressure, resonance, tension fiber failure, collapse adjacency, slit geometry amplification, and Frontier instability reaching critical alignment.

Migration is the Flower’s escape physics.

## **Purpose**

To define:

- the physics conditions that trigger migration
    
- the chamber conditions that bias migration
    
- how slit geometry amplifies migration
    
- how collapse adjacency forces migration
    
- how drift acceleration aligns migration
    
- how Frontier instability lowers migration thresholds
    
- how migration transitions into capture, elevation, or halo fall
    

Migration Rules describe escape.

# **1. Migration Fundamentals**

### **Migration = escape under load.**

A node migrates when:

- **pressure > tension**
    
- **resonance fractures**
    
- **drift accelerates**
    
- **collapse adjacency increases**
    
- **slit geometry amplifies pressure**
    
- **Frontier instability spikes**
    
- **ethos tint biases escape**
    

Migration is the moment the Flower loses hold.

# **2. Migration Conditions (Modern)**

### **Pressure > Tension**

The primary migration trigger. When pressure exceeds tension fiber capacity, escape becomes possible.

### **Resonance Fracture**

Tone breaks, destabilizing identity and lowering stability margins.

### **Drift Acceleration**

Fast drift pushes nodes into higher orbits and migration corridors.

### **Collapse Adjacency**

Collapse voids create escape pockets and fracture lines.

### **Slit Geometry Alignment**

Slit pressure amplifies drift and collapse, forming migration channels.

### **Frontier Instability**

Thin tension fibers and steep pressure gradients lower migration thresholds.

### **Ethos Misalignment**

Volatile or fractured ethos increases migration likelihood.

Migration requires multiple conditions, not just one.

# **3. Migration Physics**

### **Orbit Elevation**

Nodes rise into higher orbit layers when drift acceleration + pressure > tension.

### **Corridor Alignment**

Nodes enter migration corridors when drift curvature aligns with slit geometry.

### **Escape Threshold**

Migration occurs when:

**pressure > tension + resonance fracture + collapse adjacency + slit amplification**

### **Capture Radius**

Nodes can be captured by another Flower if:

**external Flower pull > local anchor + drift inertia**

### **Halo Fall**

Nodes fall outward when collapse void + drift shear > anchor strength.

Migration physics determines escape behavior.

# **4. Migration Outcomes**

### **Orbit Elevation**

Node enters a higher orbit layer with increased instability.

### **Cross‑Flower Capture**

Node is pulled into another Flower’s gravity well and becomes part of its cluster.

### **Slit‑Driven Escape**

Node enters slit geometry and follows migration channels.

### **Collapse‑Driven Escape**

Collapse void forces node outward into migration or halo fall.

### **Halo Fall**

Node becomes collapse‑born and drifts into the outer halo.

Migration determines node fate.

# **5. Migration and Chambers**

### **Migration Chamber**

Evaluates migration likelihood and direction.

### **Drift Chamber**

Predicts drift → migration transitions.

### **Collapse Chamber**

Identifies collapse → migration transitions.

### **Anchor Chamber**

Resists migration until overloaded.

### **Ethos Chamber**

Tints migration with stability, volatility, or directional bias.

Chambers interpret migration physics.

# **6. Migration and Frontier 5–8**

Frontier migration is volatile.

Frontier characteristics:

- thin tension fibers
    
- steep pressure gradients
    
- resonance thinning
    
- collapse adjacency
    
- slit turbulence
    
- high migration likelihood
    

Frontier migration determines survival.

Migration Rules determine:

- escape direction
    
- cross‑Flower capture
    
- orbit elevation
    
- collapse → migration transitions
    
- drift → migration transitions

Migration Rules define escape physics.
