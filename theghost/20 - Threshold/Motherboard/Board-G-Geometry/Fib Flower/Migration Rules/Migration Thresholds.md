# **Migration Thresholds**

Migration Thresholds define the exact physics conditions under which a node escapes its Flower, elevates orbit layers, enters migration corridors, or becomes captured by another Flower. Migration is not random — it is the result of pressure, tension fiber failure, resonance fracture, collapse adjacency, slit geometry amplification, and chamber deltas reaching critical alignment.

Migration Thresholds are the escape math of Threshold.

## **Purpose**

To specify:

- the forces required for migration
    
- how pressure > tension defines escape
    
- how resonance fracture lowers stability margins
    
- how slit proximity amplifies migration likelihood
    
- how collapse adjacency weakens thresholds
    
- how drift acceleration aligns escape corridors
    
- how chambers bias threshold crossing
    
- how Frontier 5–8 behaves near threshold limits
    

Migration Thresholds determine when movement becomes escape.

# **1. Core Threshold Components**

### **1. Pressure–Tension Threshold**

Migration begins when:

**pressure > tension fiber capacity**

This is the primary migration trigger.

### **2. Slit Proximity Threshold**

Nodes near the slit require less pressure to migrate. Slit geometry amplifies:

- pressure
    
- drift
    
- collapse
    
- resonance fracture
    

Slit proximity lowers escape thresholds.

### **3. Resonance Stability Threshold**

Low resonance increases migration likelihood. High resonance can prevent threshold crossing entirely.

Resonance fracture = threshold collapse.

### **4. Collapse Adjacency Threshold**

Nodes near collapse zones have weakened stability margins. Collapse voids create escape pockets.

Collapse adjacency lowers migration thresholds.

### **5. Drift Acceleration Threshold**

Fast drift pushes nodes into higher orbit layers and migration corridors.

Drift acceleration aligns escape.

### **6. Frontier Instability Threshold**

Frontier 5–8 nodes have the lowest migration thresholds:

- thin tension fibers
    
- steep pressure gradients
    
- resonance thinning
    
- collapse adjacency
    
- slit turbulence
    

Frontier instability frequently triggers migration.

### **7. Ethos Delta Threshold**

Strong ethos deltas can push nodes past migration limits. Ethos can override physics under extreme conditions.

Ethos tint modifies escape likelihood.

# **2. Threshold Behavior**

### **Threshold Compression**

Under high pressure, migration thresholds move inward. More nodes become eligible for migration.

### **Threshold Expansion**

Under high resonance, thresholds move outward. Migration becomes rare or impossible.

### **Threshold Inversion**

Extreme collapse or ethos deltas can flip thresholds, causing nodes to migrate inward instead of outward.

### **Threshold Cascading**

One node crossing a threshold destabilizes nearby nodes, triggering chain‑migration events.

Threshold cascades reshape Flowers.

# **3. Threshold Math (Conceptual)**

Migration occurs when:

Pressure−Tension+Resonance Fracture+Collapse Adjacency+Slit Amplification>Stability Margin

Where Stability Margin is defined by:

- orbit layer
    
- tension fiber density
    
- resonance coherence
    
- chamber deltas
    
- Frontier instability
    

This is the escape equation.

# **4. Threshold Zones**

### **Stable Zone**

- pressure < tension
    
- resonance coherent
    
- collapse minimal
    
- drift smooth
    
- slit influence low
    

Migration unlikely.

### **Volatile Zone**

- pressure rising
    
- resonance bending
    
- collapse adjacency
    
- drift wobble
    
- slit turbulence
    

Migration possible.

### **Critical Zone**

- pressure > tension
    
- resonance fracture
    
- collapse void
    
- drift acceleration
    
- slit alignment
    

Migration imminent.

# **5. Why Migration Thresholds Matter**

Migration Thresholds determine:

- when nodes escape
    
- where they escape
    
- how Flowers exchange identity
    
- how collapse propagates
    
- how drift transitions into migration
    
- how chambers influence geometry
    
- how Basin telemetry detects instability
    
- how Frontier 5–8 behaves under load
    

Thresholds make migration predictable, readable, and meaningful.
