1. Environment Layer — Canvas Blueprint
Domain: Physical Geography
Purpose
Represent the physical layout of all environments.
Node Types
• 	Environment nodes (primary)
• 	Environment clusters
• 	Regional anchors
Spatial Rules
• 	Nodes placed according to physical adjacency
• 	Distances approximate real traversal
• 	No curvature encoding here
Connection Logic
• 	Straight or gently curved lines
• 	Represent adjacency, not drift
Vertical Alignment
Each environment node anchors the entire Column.

2. Drift Layer — Canvas Blueprint
Domain: Motion Geometry
Purpose
Represent how motion behaves across the world.
Node Types
• 	Drift fields
• 	Drift corridors
• 	Drift loops
• 	Drift arcs
Spatial Rules
• 	Same node positions as Environment Layer
• 	Drift arcs overlay the same geography
• 	Curvature is primary visual language
Connection Logic
• 	Curved lines only
• 	Arc thickness = drift strength
• 	Arc curvature = drift curvature
Vertical Alignment
Each drift node sits directly above its environment counterpart.

3. Field Layer — Canvas Blueprint
Domain: Pressure Fields & Gradients
Purpose
Represent invisible forces shaping motion and identity.
Node Types
• 	Pressure fields
• 	Field cores
• 	Field gradients
• 	Field boundaries
Spatial Rules
• 	Same layout as lower layers
• 	Fields drawn as soft zones or halos
• 	Gradients shown as directional shading or arrows
Connection Logic
• 	Gradient lines
• 	Field‑to‑field influence arcs
Vertical Alignment
Field nodes align with drift and environment nodes.

4. Collapse Layer — Canvas Blueprint
Domain: Collapse Vectors & Spirals

Node Types

• 	Collapse residues
Spatial Rules

• 	Spirals drawn at collapse‑aligned nodes
• 	Vectors show collapse direction
Connection Logic
• 	Inward‑curving lines
• 	Spiral geometry
• 	No straight lines
Vertical Alignment
Collapse nodes sit above field nodes.

Domain: Signal Propagation & Interference

Cross‑Layer Rules (Apply to All Seven)
1. Spatial Consistency
Node positions must remain identical across all canvases.
2. Vertical Linking
Each node must link to its siblings in the other layers.
3. Layer‑Specific Geometry
Each layer uses its own visual language:
• 	Environment = adjacency
• 	Drift = curvature
• 	Field = gradients
• 	Collapse = spirals
• 	Identity = halos
• 	Role = geometry
• 	Signal = oscillation
4. No Contradictions
A node’s behavior must be explainable through its upstream physics.
5. Columns
Every environment must form a complete Column across all layers.
