Overview
This file provides clear, concrete examples of how the Player Choice Tree operates during gameplay.
Each example demonstrates one of the three core creation actions:
1. 	Reveal an Existing Node
2. 	Create a New Node
3. 	Connect Two Existing Nodes
These examples show how the world expands, stabilizes, or reveals hidden structure based on player decisions.
