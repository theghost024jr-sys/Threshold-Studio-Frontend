Purpose
The Navigation Map provides a single surface from which all seven layers of the Multi‑Layer Map System can be accessed.
It is the entry point for moving between layers, columns, and physics domains.
This map does not contain world content.
It contains links to maps.

1. Structure
The Navigation Map contains:
• 	Seven Layer Cards
• 	Column Index Card
• 	System Architecture Card
• 	Layer Index Card
• 	Optional: Quick‑Jump Cards for major clusters (Distortion, Stability, Neutral)
These cards are arranged in a vertical stack to mirror the seven‑layer architecture.
