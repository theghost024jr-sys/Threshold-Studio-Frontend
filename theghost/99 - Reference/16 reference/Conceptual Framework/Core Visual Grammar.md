(Threshold — Visual Architecture Spine)
Purpose
The Core Visual Grammar defines how characters, spirit animals, and environmental entities appear and move within Threshold.
It establishes a unified aesthetic language that is:
• 	Low‑complexity
• 	High‑expression
• 	Rhythmically alive
• 	Emotionally readable
• 	Modular and scalable
This grammar adapts the Sinker‑Sound‑style motion template into Threshold’s symbolic ecology, ensuring every entity feels like part of the same living system.

1. Visual Essence
Threshold’s visual identity is built on expressive simplicity:
• 	Low‑poly silhouettes
• 	Flat, warm color palettes
• 	Minimal shading
• 	Soft, rhythmic motion
• 	Clear emotional signatures
Every entity — spirit animal, character, or environmental node — must be readable at a glance, even when small or partially obscured.
Design Principles
• 	Clarity over detail
• 	Emotion over realism
• 	Symbol over anatomy
• 	Motion over texture

2. Shape Language
Threshold uses a symbolic geometry system:
Primary Forms
• 	Circles / Ovals → gentleness, receptivity, drift
• 	Triangles → alertness, direction, intent
• 	Squares / Rectangles → grounding, stability, boundary
• 	Curved planes → emotional resonance, softness
• 	Sharp planes → tension, misalignment
Spirit Animals
Spirit animals follow a low‑poly, toy‑like silhouette, inspired by Sinker Sound’s fish:
• 	Simple bodies with 1–3 major forms
• 	Exaggerated features for emotional clarity
• 	Minimal facial detail (eyes carry the expression)
• 	No micro‑textures
• 	No anatomical realism
Each species has a signature silhouette that communicates its archetype.

Warm Spectrum

• 	Safety

Cool Spectrum

Neutral Spectrum

4. Shading & Lighting
Threshold uses minimalist lighting:
• 	One directional light
• 	Soft ambient fill
• 	No harsh shadows
• 	No specular highlights
• 	Optional rim light for emphasis
The world should feel soft, breathable, and emotionally accessible.

5. Motion Grammar (Sinker‑Sound Adaptation)
This is the heart of the file — the motion template adapted from Sinker Sound’s fish animations.
Core Motion Principles
• 	Everything breathes
Idle states have gentle rhythmic motion.
• 	Emotion is expressed through timing
Faster = alert
Slower = calm
Staccato = misaligned
Smooth = aligned
• 	Motion is musical even without music
Internal beats, pulses, and cycles define behavior.
• 	Snaps and pulses replace realism
Motion is symbolic, not anatomical.

5.1 Idle Motion Template
(Adapted from Sinker Sound’s fish bobbing)
All spirit animals share a baseline idle loop:
• 	Vertical bob (2–4% body height)
• 	Subtle rotation (1–3 degrees)
• 	Soft scale pulse (1–2%)
• 	Eye blink cycle (every 3–7 seconds)
This creates a sense of aliveness without urgency.

5.2 Emotional Motion States
Aligned
• 	Slow, smooth bob
• 	Gentle easing
• 	Warm color accent pulse
• 	Slight forward drift
Curious
• 	Faster bob
• 	Head tilt
• 	Small lateral movements
• 	Eye tracking
Alert
• 	Sharper easing
• 	Quick snaps
• 	Reduced bob amplitude
• 	Color accent brightens
Misaligned
• 	Staccato motion
• 	Off‑beat pulses
• 	Slight jitter
• 	Color accent desaturates
Threshold State
• 	Motion slows
• 	Body compresses slightly
• 	Eyes soften
• 	Color shifts toward neutral

5.3 Interaction Motion Template
(Inspired by Sinker Sound’s hook‑snap feedback)
When a player interacts with a spirit animal:
• 	Snap-in: quick scale-down (3–5%)
• 	Hold: 0.1–0.2s
• 	Release: overshoot scale-up (2–4%)
• 	Settle: return to idle
This creates a tactile, rhythmic response.

6. Environmental Motion Grammar
Environments follow the same rhythmic principles:
• 	Water planes pulse gently
• 	Grass sways on a slow beat
• 	Light flickers subtly
• 	Environmental nodes breathe like characters
Nothing is static.
Everything participates in the emotional physics.

7. UI Grammar
UI elements follow the same visual and motion rules:
• 	Rounded shapes
• 	Thick outlines
• 	Flat colors
• 	Soft pulses
• 	Snappy transitions
UI is not separate from the world — it shares the same rhythmic language.
