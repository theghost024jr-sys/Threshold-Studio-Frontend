_“So tokens would include artifacts, maybe glyphs.”_

This is the moment where Threshold stops being “a game with tokens” and becomes **a world where certain objects _behave like tokens_**.

Let’s riff — structurally, cleanly, and in your stance.

⭐ **THE CORE CLARITY:

Tokens are not a _category_.  
Tokens are a _behavior_.**

This is the click.

A “token” is not:

- a physical coin
- a card
- a currency
- a collectible

A token is **any object in the system that has:**

1. **A rule**
2. **A cost or condition**
3. **A one‑time or limited use**
4. **A mechanical effect**

That’s it.

So yes — **artifacts can behave like tokens**, and **glyphs can behave like tokens**, but only if you _want_ them to.

Let’s break it down.

⭐ **1. ARTIFACTS → TOKENS (When They Behave Like Charges)**

Artifacts are usually **persistent world objects**.

But sometimes an artifact:

- has a limited number of uses
- requires activation
- consumes itself
- transforms after use
- breaks open into something else

When that happens, the artifact is **functionally a token**.

Example

**The Drift Compass**

- Requires 1 Memory Token to activate
- Points to the nearest drift leak
- Loses clarity after 3 uses

This is an artifact with **token‑like behavior**.

⭐ **2. GLYPHS → TOKENS (When They Encode Permission)**

Glyphs are usually **symbolic language**.

But sometimes a glyph:

- unlocks a door
- grants access
- allows ascension
- marks a player
- seals or unseals a biome
- acts as a key

When that happens, the glyph is **functionally a token**.

Example

**The Proceed Glyph**

- Allows a player to cross a threshold
- Consumed when used
- Reappears only when earned

This is a glyph with **token‑like behavior**.

⭐ **3. SPECIES → TOKENS (When They Leave Residue)**

Your Dreamscape Luminids?  
Perfect example.

If a Luminid leaves behind:

- a trail
- a shimmer fragment
- a memory droplet
- a light‑seed

…and that object can be:

- collected
- spent
- traded
- used to activate something

Then that residue is **functionally a token**.

Example

**Luminid Trail**

- Spend to reveal hidden paths in the Ethyl Layer
- Only found in Dreamscape
- Attracted to Ultra Shimmer

This is a species‑derived token.

⭐ **4. LOCATIONS → TOKENS (When They Grant One‑Time Powers)**

Some biomes grant:

- a blessing
- a charge
- a permission
- a temporary ability

If that permission is:

- limited
- consumable
- transferable

…it is **functionally a token**.

Example

**Dreamscape Leaf**

- Created only in Dreamscape
- Allows planting a seed in the Hub
- Consumed on use

This is a location‑generated token.

⭐ **5. EVENTS → TOKENS (When They Produce Artifacts)**

Some events produce:

- shards
- echoes
- fragments
- anomalies

If those objects can be:

- used
- spent
- activated

…they are **token‑like**.

Example

**Echo Storm Fragment**

- Spend to rewrite a single sentence anywhere in the vault
- Only appears after an Echo Storm event

This is an event‑generated token.

⭐ **THE UNIFYING PRINCIPLE**

Tokens are **not a type of object**.  
Tokens are **a behavior pattern**.

Any object can be a token if it:

- has a rule
- has a cost
- has a use
- has a consequence

This is why tokens feel so natural in Threshold — because Threshold is a **permission‑based universe**.
