⭐ **1. Without tokens, every action is flat**

If every action is:

- free
- equal
- always available

…then the system has **no verticality**.

Everything becomes:

- Add link
- Add tag
- Make note
- Move note
- Fix drift

All on the same plane.

Threshold collapses into a **sandbox wiki**.

There’s no tension.  
No cost.  
No rarity.  
No “should I do this now or later.”  
No “I earned this.”  
No “I’m saving this for the right moment.”

Tokens create **verticality** — a second dimension of play.

⭐ **2. Tokens create _meaningful choice_**

Without tokens:

- You can always create an artifact
- You can always spawn a path
- You can always open a sealed note
- You can always do the big thing

So the big thing stops being big.

With tokens:

- “Do I spend this now?”
- “Do I save it for later?”
- “Do I trade it?”
- “Do I risk losing it?”
- “Do I use it to help someone else?”

Tokens create **decision pressure**, which creates **story**.

- Luminid Trails
- Aurora Seeds
- Shimmer Fragments
- Dual‑Action Leaves

…then Dreamscape becomes a **mechanical biome**, not just a narrative one.

Tokens let biomes have:

- resources
- specialties
- unique physics
- reasons to visit
- reasons to return

Without tokens, biomes are just folders.
