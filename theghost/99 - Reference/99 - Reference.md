99 – Reference
==============

99‑Reference is the **temporary scaffolding organ** that holds all fragments,
concepts, seeds, prototypes, and partial structures before they collapse into
the main 00–14 architecture.

It is not a final organ.  
It is a **sorting engine**.


I. Purpose
----------

99‑Reference exists to:
- prevent drift during world construction  
- hold unstable or partial files  
- reveal emerging chambers  
- stabilize fragments long enough to classify them  
- prepare all content for collapse into the main architecture  

99‑Reference is the **pre‑architecture organ**.


II. Structure
-------------

99‑Reference contains two types of chambers:

1. **Stable Chambers**  
   These survive consolidation:
   - Characters  
   - Cosmology & Physics  
   - System Mechanics  
   - Conceptual Frameworks  
   - Growth Layers  
   - Liminal Systems  
   - Lumen Seed Vault  
   - Prototypes  
   - Assets  

2. **Temporary Chambers**  
   These collapse after sorting:
   - Narrative Seeds  
   - _Staging  
   - Residue & Resonance  
   - Memory  
   - Templates  
   - Mythosync  
   - Echo Studies  
   - Fib Layer  
   - Geometry & Topology  
   - Signals & Shimmer  
   - Physics of Meaning  
   - Master Files  


III. Behavior
-------------

99‑Reference follows four rules:

1. **Sorting precedes meaning**  
   Files must be placed before they can be understood.

2. **Chambers reveal gravity**  
   The more files a chamber attracts, the more real it becomes.

3. **Temporary scaffolding collapses**  
   Once sorting is complete, scaffolding disappears.

4. **Reference migrates into architecture**  
   All stable chambers move into the 00–14 system.


IV. Collapse Dynamics
---------------------

99‑Reference collapses in three phases:

1. **Chamber Consolidation**  
   Stable chambers strengthen and become organs.

2. **Scaffolding Collapse**  
   Temporary chambers dissolve and release residue.

3. **Migration**  
   Stable chambers migrate into:
   - 01 Physics  
   - 02 Signals  
   - 07 Species / Artifacts  
   - 11 Substrates  
   - 12 Liminal Systems  
   - 14 Vault  

99‑Reference ends when all content has migrated.


V. Reference Flow
-----------------

The Reference Flow is:

1. Intake  
2. Sorting  
3. Chamber Formation  
4. Consolidation  
5. Collapse  
6. Migration  
7. Integration  

This flow ensures the world remains stable during construction.


VI. Reference Failure Modes
---------------------------

1. **Reference Saturation**  
   Too many files → drift noise → chamber instability.

2. **Reference Fracture**  
   Chambers split unpredictably → misclassification.

3. **Reference Drift**  
   Files float between chambers → sorting failure.

4. **Reference Collapse**  
   Premature collapse → architecture corruption.


VII. Reference Recovery
-----------------------

Recovery requires:
- re‑sorting  
- chamber reinforcement  
- drift clearing  
- scaffolding stabilization  
- controlled collapse  


VIII. Summary
-------------

99‑Reference =  
sorting + scaffolding + consolidation + collapse + migration

It is the **temporary organ** that makes the permanent architecture possible.
