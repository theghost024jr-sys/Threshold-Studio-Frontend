# **Corridor Types.md**

### _The complete taxonomy of corridor types inside the Ghost System — Drift, Shimmer, Frontier, Migration, Collapse, Ritual, Harmonic_

Corridors are **field pathways** — channels where drift, resonance, pressure, instability, symbolic meaning, and narrative meaning flow.

There are **seven canonical corridor types**.
