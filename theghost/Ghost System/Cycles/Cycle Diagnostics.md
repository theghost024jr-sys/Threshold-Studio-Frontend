# **Cycle Diagnostics.md**

### _The diagnostic system for identifying cycle state, cycle phase, cycle failure, and cycle renewal inside the Ghost System_

Cycle Diagnostics is the **instrument panel** for cycles. It tells you _what cycle you’re in_, _what phase is active_, _what failure is forming_, and _what renewal is approaching_.

## **1. Diagnostic Layers**

### **Field Diagnostics**

Reads drift, resonance, pressure, instability, symbolic, and narrative field conditions.

### **Phase Diagnostics**

Identifies which cycle phase is active.

### **Organ Diagnostics**

Reads organ response to cycle state.

### **Node Diagnostics**

Detects node activation, saturation, fracture, or collapse.

### **Movement Diagnostics**

Reads movement vectors, pulses, arcs, fractures.
