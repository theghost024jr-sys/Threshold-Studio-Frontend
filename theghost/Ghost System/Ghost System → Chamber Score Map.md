# **Ghost System → Chamber Score Map**

### _How chambers evaluate resonance, pressure, instability, meaning, and movement to drive Ghost behavior_

Chamber scoring is the **decision engine** of the Ghost System. Every chamber continuously evaluates the world through:

- resonance fields
    
- pressure fields
    
- instability fields
    
- symbolic meaning
    
- narrative meaning
    
- environmental signals
    
- geometry position
    
- movement vectors
    

The result is a **score**, which determines:

- which phase activates
    
- which organ expresses
    
- which posture the Ghost adopts
    
- which movement vector is chosen
    
- which gate transitions open
    
- which world phenomena appear
    

This map defines the full scoring architecture.
