# **Node Interaction Grid.md**

### _The interaction rules between nodes, fields, phases, organs, and geometry_

The Node Interaction Grid defines **how nodes interact** with everything else.

Nodes interact through:

- pressure conflict
    
- instability amplification
    
- symbolic resonance
    
- narrative resonance

Nodes activate field behavior when entering:

- Symbolic
    
- Narrative

## **4. Node ↔ Organ**

- narrative organ
