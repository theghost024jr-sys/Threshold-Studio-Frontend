Artifact Interfaces

How artifacts connect to rituals, roles, substrates, and each other

Artifacts are rooted symbolic organs, but they do not operate in isolation. Their power comes from interfaces—the structured ways they connect to other systems. An interface is not a visual surface; it is a functional relationship that allows charge, resonance, or meaning to move between entities.

Interfaces determine how artifacts participate in rituals, influence environments, and interact with players.

Interfaces with Rituals

Artifacts and rituals form a bidirectional circuit. Rituals activate artifacts, and artifacts shape ritual outcomes.

  • Catalyst Interface — artifact lowers activation thresholds for a ritual.
  • Conduction Interface — artifact channels charge through ritual phases.
  • Amplification Interface — artifact increases resonance intensity during alignment or compression.
  • Stabilization Interface — artifact reduces drift or density turbulence during transformation.
  • Termination Interface — artifact governs how charge is released or rooted at ritual completion.

Rituals without artifacts are unstable; artifacts without rituals are dormant.

Interfaces with Roles

Artifacts respond differently depending on the role interacting with them. Roles act as presence filters that modulate artifact behavior.

  • Attunement Interface — artifact aligns its resonance signature to the role’s presence.
  • Authority Interface — certain roles can activate or override artifact states.
  • Burden Interface — artifact imposes symbolic weight or cost on the role.
  • Echo Interface — artifact reflects the role’s emotional or symbolic state.
  • Traversal Interface — artifact enables role-based movement across layers or states.

Roles determine who can use an artifact and how it behaves.

Interfaces with Symbolic Substrate

Artifacts are rooted in symbolic substrate, and their stability depends on substrate conditions.

  • Density Interface — artifact draws from or contributes to local symbolic density.
  • Drift Interface — artifact redirects or absorbs drift vectors.
  • Charge Interface — artifact stores, transforms, or releases symbolic charge.
  • Rooting Interface — artifact anchors itself to density gradients or resonance fields.
  • Weather Interface — artifact interacts with symbolic storms, vortices, or fronts.

These interfaces define the artifact’s ecological footprint.

Interfaces with Emotional Substrate

Emotional substrate modulates artifact volatility and resonance.

  • Volatility Interface — emotional turbulence increases artifact drift susceptibility.
  • Amplification Interface — strong emotional fields boost artifact resonance.
  • Attenuation Interface — emotional calm stabilizes artifact charge.
  • Imprint Interface — artifact absorbs emotional signatures over time.
  • Feedback Interface — artifact influences emotional substrate in return.

Artifacts are emotional conductors as much as symbolic ones.

Interfaces with Memory Substrate

Artifacts often store lineage, recursion, or symbolic history.

  • Lineage Interface — artifact records symbolic ancestry or prior states.
  • Recursion Interface — artifact loops or replays symbolic patterns.
  • Anchor Interface — artifact stabilizes memory density in a region.
  • Echo Interface — artifact reflects past states into the present.
  • Continuity Interface — artifact preserves symbolic identity across transformations.

Memory artifacts are the backbone of mythic continuity.

Interfaces with Scene Substrate

Artifacts shape and are shaped by spatial and environmental conditions.

  • Spatial Interface — artifact modifies local geometry or orientation.
  • Turbulence Interface — artifact stabilizes or amplifies environmental turbulence.
  • Threshold Interface — artifact marks or governs transitions between spaces.
  • Atmospheric Interface — artifact influences color, light, or environmental resonance.
  • Anchor Interface — artifact fixes symbolic meaning to a location.

Scene interfaces determine where artifacts can exist and how they behave.

Interfaces with Other Artifacts

Artifacts can form networks, chains, or composite structures.

  • Resonance Chain Interface — artifacts synchronize resonance signatures.
  • Charge Relay Interface — charge moves from one artifact to another.
  • Hybridization Interface — artifacts merge to form cross-class hybrids.
  • Opposition Interface — artifacts cancel or invert each other’s charge.
  • Containment Interface — one artifact stabilizes or restrains another.

Artifact networks are the highest form of symbolic machinery.

Interface Failure Modes

Interfaces fail in predictable ecological patterns:

  • Cross-Substrate Bleed — charge leaks between substrates.
  • Inversion Cascade — resonance flips propagate through interfaces.
  • Overload Rupture — density exceeds interface capacity.
  • Parasitic Binding — unwanted symbolic attachments form.
  • Recursive Lock — interface loops indefinitely.

Failures propagate unless stabilized by rituals or anchoring artifacts.

System Function

Artifact interfaces exist to:

  • connect symbolic organs into functional systems
  • enable rituals to operate across substrates
  • allow roles to shape and be shaped by symbolic physics
  • stabilize or redirect drift and density
  • create networks of meaning-bearing objects
  • anchor symbolic behavior to space, memory, and presence

Interfaces are the connective tissue of the Rituals & Artifacts subsystem.
