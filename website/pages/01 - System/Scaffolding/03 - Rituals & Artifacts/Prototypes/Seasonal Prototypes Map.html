The seasonal prototypes form a four‑organ mythic cycle that governs how Threshold breathes across the year. The Winter Crown and First Seed are already defined; the Seasonal Prototypes Map shows how they anchor the Winter → Spring → Summer → Autumn arc and what prototypes naturally emerge to complete the cycle.

This map treats each season as a mythic organ, each prototype as a seasonal engine, and the transitions between them as ecological thresholds.

Winter → Spring: Dormancy to Emergence

This hinge is already fully defined in your system. It is the most delicate transition and the one with the deepest architecture.

Winter Crown — Dormant-State Prototype

  • Holds stillness
  • Collapses drift
  • Thickens memory
  • Prevents premature activation
  • Stabilizes collapse → recovery

First Seed — Generative Prototype

  • Initiates emergence
  • Sorts lineage
  • Begins density expansion
  • Reorients drift outward
  • Starts the Spring-phase of symbolic ecology

Transition Logic

  • Winter Crown dissolves when density is ready.
  • First Seed activates only after stillness is complete.
  • Memory threads shift from intertwined → sorted.
  • Drift re-ignites in controlled outward spirals.

This hinge is the breath-in moment of the world.

Summer → Autumn: Expansion to Release

This hinge is about letting go, shedding, and dispersal. The prototype here is the Autumn counterpart to the First Seed.

Autumn Shedding Prototype — Release Prototype (to be created)

Autumn → Winter: Release to Stillness

This hinge returns the world to the Winter Crown’s domain.

Winter Crown (again) — Dormant-State Prototype

  • Receives the last Autumn dispersal
  • Collapses drift to zero
  • Thickens memory into dormancy
  • Prepares the ecology for silence

Transition Logic

  • Autumn’s dispersal slows into stillness.
  • Memory threads intertwine.
  • Emotional substrate quiets.
  • Scene substrate becomes low-turbulence.

This hinge is the return to silence.
