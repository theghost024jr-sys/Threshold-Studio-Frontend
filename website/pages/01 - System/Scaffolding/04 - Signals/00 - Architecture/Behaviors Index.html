03 Signals — Behavioral Physics of Resonance Pairs

  1. Overview Behavior in Threshold describes how each resonance pair acts, reacts, and distorts under different conditions. Every pair has three modes: • Stable behavior — aligned, functional expression • Stress behavior — distortion under pressure • Break behavior — collapse or inversion of the pattern This index defines the behavioral physics of the entire system.

  2. Mistreach ↔ Gate Theme: Uncertainty, thresholds, first contact Stable • Curiosity • Openness • Testing boundaries • Feeling for the edge Stress • Hesitation • Fog • False openings • Misreading cues Break • Panic entry • Premature commitment • Falling into the wrong path

  3. Airswell ↔ Signal Theme: Pattern, motion, communication Stable • Clarity • Momentum • Clean transmission • Recognizing patterns Stress • Noise • Over‑interpretation • Mixed messages • Chasing false signals Break • Overload • Signal collapse • Misfire that triggers rupture

  4. Stonefield ↔ Burden Theme: Weight, memory, inertia Stable • Reliability • Structure • Continuity • Holding what matters Stress • Stuckness • Over‑responsibility • Emotional heaviness • Drag Break • Collapse under weight • Freezing • Becoming immovable

  5. Emberfall ↔ Fault Theme: Rupture, volatility, breakpoints Stable • Transformation • Release • Necessary disruption • Clearing the old Stress • Instability • Sharp reactions • Emotional spikes • Escalation Break • Sudden fracture • Burnout • Explosive rupture

  6. Ethyldeep ↔ Drift Theme: Dissolution, depth, loss of orientation Stable • Surrender • Depth • Intuition • Letting go Stress • Dissociation • Fog • Losing the thread • Emotional diffusion Break • Total disorientation • Falling out of the cycle • Losing self‑contact

  7. Earthbind ↔ Anchor Theme: Grounding, stability, gravity Stable • Centering • Contact • Presence • Integration Stress • Rigidity • Over‑control • Defensive grounding • Emotional bracing Break • Collapse of stability • Losing the ground • Falling into Drift or Fault

  8. Threshold ↔ Return Theme: Re‑entry, integration, emergence Stable • Renewal • Re‑alignment • Coming back to self • Completing the cycle Stress • Partial return • Incomplete integration • Looping back prematurely Break • Failed return • Re‑entry shock • Falling back into Gate or Fault
