The Master Blueprint of Threshold

Threshold is built from seven major systems, each representing a different axis of meaning.
These systems interlock in a strict dependency order, forming a clean, modular, non‑circular architecture.

This document defines:

  • the systems
  • their order
  • their dependencies
  • their boundaries
  • their folder logic
  • their link logic

It is the map of the map — the rules of the rules.

1. The Threshold Stack

Threshold is organized into seven layers of abstraction, from most fundamental to most expressive:

  1. Meta Systems — rules of the world
  2. Layers — physics substrate
  3. Signals — behavioral substrate
  4. Species — embodiment
  5. Roles — archetypal behavior
  6. Map — spatial interface
  7. Myth — narrative substrate

These are not interchangeable.
Each depends on the one above it.

2. Folder Structure

The folder structure mirrors the dependency stack:

00 System Architecture/ 01 Meta Systems/ 02 Layers/ 03 Signals/ 04 Species/ 05 Roles/ 06 Map/ 07 Myth/

This ensures:

  • no circular dependencies
  • clean navigation
  • predictable link logic
  • modular expansion

3. System Definitions

01 Meta Systems

Defines the global rules:

  • Layer physics
  • Signal Types
  • Signal Drift
  • Elemental Overlays
  • Species Architecture
  • Archetypal Roles
  • Threshold Map Logic
  • Threshold Myth Progress

Meta Systems = the operating system of Threshold.

02 Layers

Six physics substrates:

  • Air
  • Earth
  • Ember
  • Ethyl
  • Mist
  • Stone

Layers define where signals live and how they behave under pressure.

03 Signals

Behavioral substrate:

  • Signal Types
  • Drift
  • Expression patterns

Signals define how a spirit behaves.

04 Species

Embodiment system:

  • Species families
  • Variants
  • Images
  • Resonance clusters

Species define what form a spirit takes.

05 Roles

Archetypal behavior:

  • Sentinel
  • Weaver
  • Hunter
  • Oracle
  • Echo
  • Lantern

Roles define why a spirit behaves the way it does.

06 Map

Spatial interface:

  • nodes
  • pathways
  • regions
  • drift visualization

The map shows where meaning moves.

07 Myth

Narrative substrate:

  • mythic eras
  • cosmology
  • unfolding logic

Myth defines how the world tells its story.

4. Dependency Order

Each system depends on the ones above it:

  • Layers depend on Meta Systems
  • Signals depend on Layers
  • Species depend on Signals + Layers
  • Roles depend on Signals + Layers
  • Map depends on Layers + Drift
  • Myth depends on Map + Layers

This prevents circular logic and keeps the architecture stable.

5. Link Logic

Each file links only to:

  • the systems it depends on
  • the systems that depend on it
  • the components it defines

Nothing else.

This keeps the system:

  • modular
  • discoverable
  • non‑redundant
  • non‑circular

6. Naming Conventions

  • Each system has a parent file defining the rules.
  • Each component has its own file (e.g., each Layer, each Role).
  • Variants and images live under Species.
  • Nodes and pathways live under Map.
  • Mythic eras live under Myth.

7. Expansion Rules

When adding new content:

  • If it defines a rule → Meta Systems
  • If it defines physics → Layers
  • If it defines behavior → Signals
  • If it defines embodiment → Species
  • If it defines archetype → Roles
  • If it defines space → Map
  • If it defines story → Myth

This keeps the system clean forever.
