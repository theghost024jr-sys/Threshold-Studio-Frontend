Overview The Threshold Entity Index catalogs every recognized entity‑class in Threshold. An entity is anything that: • exhibits behavior • interacts with fields • expresses emotional physics • participates in Drift/Mist/Shimmer dynamics • influences or is influenced by collapse • holds symbolic density • has a readable state or arc Entities include roles, species, constructs, forces, artifacts, and environmental intelligences. This index defines the taxonomy, classification, and placement of all entity types.

Entity Classes

  1. Roles Human‑adjacent, stance‑based entities defined by behavior, perception, and field interaction. • Witness • Curator • Warden • Navigator • Binder • (additional roles added as defined) Roles are behavioral entities, not characters.

  2. Species Environment‑bound organisms shaped by Drift, Mist, Shimmer, Stone, Ember, Ethyl, or Collapse. Ruins Species • Dust Hares • Dust Hairs • Stone Forms • (future Ruins species expand here) Other Zone Species (populated as zones are defined) Species are ecological entities.

  3. Constructs Non‑biological, non‑role entities formed by resonance, collapse, or symbolic density. Examples include: • Stone Forms (also listed under species due to hybrid nature) • Resonance Pillars • Collapse Echoes • Memory Stones • Shimmer Lattices Constructs are structural entities.

  4. Forces Non‑physical, field‑level entities that shape behavior and environment. • Drift • Mist • Shimmer • Stone • Ember • Ethyl • Heat • Collapse Forces are field entities.

  5. Weather Systems Dynamic, field‑driven entities that behave like storms, tides, or atmospheric patterns. • Saturation Storms • Fracture Tempests • Drift Fogs • Collapse Gyres • Pressure Fronts • Collapse Scars Weather systems are dynamic entities.

  6. Artifacts Objects that metabolize meaning, store resonance, or alter field behavior. Examples include: • Memory Anchors • Shimmer Keys • Collapse Residue Artifacts • Symbolic Containers • Field‑Bound Tools Artifacts are meaning‑bearing entities.

  7. Substrate Entities Entities that exist within or as part of the substrate layers. • Symbolic Substrate Nodes • Emotional Substrate Currents • Narrative Substrate Threads • Field Rhythm Intelligence • Field Dreaming State Substrate entities are deep‑layer entities.

  8. Gate Entities Entities associated with transitions, thresholds, and boundary crossings. • Gates • Gate Echoes • Gate Guardians (if defined) • Gate Residue Patterns Gate entities are liminal entities.

Entity Behaviors Entities express behavior through: • Scripts (behavioral sequences) • Arcs (state changes) • Resonance Patterns • Field Interactions • Emotional Physics • Collapse Responses Behavior is the defining trait of entityhood.

Entity Taxonomy Rules

  1. If it behaves, it is an entity.
  2. If it alters fields, it is an entity.
  3. If it expresses emotional physics, it is an entity.
  4. If it holds symbolic density, it is an entity.
  5. If it is purely environmental with no behavior, it is not an entity.
  6. If it is purely conceptual with no field expression, it is not an entity.
