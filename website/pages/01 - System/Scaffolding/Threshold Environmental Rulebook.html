Overview Threshold environments are not decorative. They are expressions of the system’s physics — shaped by the Master Cycle, distorted by the Shadow Cycle, and animated by the Roles and Triads. This rulebook defines: • how environments form • how they behave • how they collapse • how they recover • how players perceive and interact with them Every environment in Threshold is a phase‑driven space.

  1. Environmental Identity Every environment must declare: • Phase (Gate, Signal, Fault, Drift, Anchor, Return, Burden) • Shadow Phase (optional, for collapse states) • Triad Influence (which engine shapes it) • Role Influence (which archetype governs it) This creates the environment’s identity signature. Example: “Signal environment influenced by Initiation Engine and Signal‑Keeper.”

  2. Environmental Geometry Each phase has a distinct geometric logic: • Gate: thresholds, openings, liminal edges • Signal: patterns, rhythms, repeating structures • Fault: cracks, breaks, pressure lines • Drift: soft, dissolving, low‑contrast geometry • Anchor: heavy, grounded, stable forms • Return: spirals, recombining structures • Burden: stone, weight, memory‑dense geometry Shadow geometry is the collapsed version: • False Gate → misleading corridors • Noise Spiral → contradictory patterns • Destructive Rupture → unstable fractures • Dissociation → disappearing edges • Rigidity → locked, immovable structures • Failed Re‑Entry → broken loops • Immobilizing Weight → gravity sinks

  3. Environmental Lighting Lighting is not aesthetic — it’s behavioral. • Gate: soft, directional, inviting • Signal: pulsing, rhythmic, information‑dense • Fault: sharp contrast, flicker, pressure spikes • Drift: diffuse, fogged, low‑definition • Anchor: warm, steady, gravitational • Return: recombining, swirling, coherent • Burden: dim, heavy, memory‑weighted Shadow lighting collapses: • False Gate → misleading glows • Noise Spiral → chaotic flicker • Destructive Rupture → violent strobing • Dissociation → fading light • Rigidity → frozen, unchanging light • Failed Re‑Entry → broken illumination • Immobilizing Weight → oppressive dimness

  4. Environmental Behavior Environments behave according to their phase. Gate Behavior • Opens paths • Reveals edges • Encourages exploration Signal Behavior • Communicates patterns • Responds to attention • Builds momentum Fault Behavior • Breaks under pressure • Releases energy • Forces movement Drift Behavior • Softens boundaries • Dissolves structure • Slows momentum Anchor Behavior • Grounds the player • Stabilizes movement • Restores contact Return Behavior • Reassembles meaning • Reconnects pathways • Completes loops Burden Behavior • Holds memory • Adds weight • Creates continuity Shadow behaviors invert these functions.

  5. Environmental Collapse States Every environment has a collapse threshold. When exceeded, it shifts into its Shadow Phase: • Gate → False Gate • Signal → Noise Spiral • Fault → Destructive Rupture • Drift → Dissociation • Anchor → Rigidity • Return → Failed Re‑Entry • Burden → Immobilizing Weight Collapse is triggered by: • overload • misalignment • unresolved pressure • incorrect role interaction • triad imbalance

  6. Environmental Recovery Recovery follows the Recovery Vector from the Overlay: • False Gate → Signal • Noise Spiral → Fault • Destructive Rupture → Drift • Dissociation → Anchor • Rigidity → Return • Failed Re‑Entry → Burden • Immobilizing Weight → Gate Recovery is not a reversal — it’s a forward re‑entry into the next functional phase.

  7. Environmental Interaction Rules Players interact with environments through: • attention • movement • pressure • choice • role alignment Each environment responds differently: • Gate reacts to approach • Signal reacts to focus • Fault reacts to pressure • Drift reacts to stillness • Anchor reacts to grounding • Return reacts to synthesis • Burden reacts to memory Shadow environments react with distortion.

  8. Environmental Transitions Transitions follow the Master Cycle unless collapse occurs. Functional transitions: Gate → Signal → Fault → Drift → Anchor → Return → Burden → Gate Shadow transitions: False Gate → Noise Spiral → Destructive Rupture → Dissociation → Rigidity → Failed Re‑Entry → Immobilizing Weight → False Gate Transitions must be felt, not just seen.

  9. Environmental Templates Each environment can be built using: • Geometry rules • Lighting rules • Behavior rules • Collapse rules • Recovery rules Templates can be layered, nested, or combined.

  10. Environmental Purpose Environments are not scenery. They are expressions of the system’s emotional physics. They teach the player: • how meaning forms • how meaning breaks • how systems collapse • how systems recover • how cycles move This is the heart of Threshold.
