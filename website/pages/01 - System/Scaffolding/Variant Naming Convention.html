1. Structure Every Variant name follows a two‑part canonical structure:

Where: • Curvature Prefix encodes the Variant’s class • Unique Epithet expresses its specific pattern, behavior, or mythic signature This keeps the Index sortable while preserving expressive freedom.

  1. Curvature Prefixes These are short, stable, and never change.

These prefixes are intentionally terse — they behave like species codes or airport identifiers.

  1. Unique Epithet Rules The epithet is where the poetry lives, but it still follows rules: • One or two words max • Evokes the Variant’s core behavior • Avoids generic terms (e.g., “Shadow,” “Echo,” “Variant”) • Uses concrete or mythic language • No overlap across curvature classes • Capitalized (e.g., “Glassweaver,” “Hollow Step,” “Return Coil”) Think of it as the Variant’s face.

  2. Full Examples To show the system in motion: Reintegration • RE‑Glassweaver • RE‑Return Coil • RE‑Quiet Binding Stable Divergence • SD‑Hollow Step • SD‑Split Lantern • SD‑Wanderline Collapse • CL‑Ash Spiral • CL‑Fracture Bloom • CL‑Null Ember You can feel how the prefix anchors the class while the epithet carries the emotional physics.

  3. Index Behavior Variants sort automatically by:

  4. Curvature Class

  5. Epithet (alphabetical)

  6. Version number (optional, if you ever introduce revisions) Example:

RE‑Glassweaver RE‑Quiet Binding SD‑Hollow Step SD‑Split Lantern CL‑Ash Spiral CL‑Fracture Bloom

Clean. Predictable. Expandable.

  1. Optional: Sub‑Variant Suffix If you ever need micro‑variants or evolutions:

Suffixes are lowercase, short, and functional: • ‑a, ‑b, ‑c for simple branches • ‑α, ‑β, ‑γ for experimental or unstable forms • ‑I, ‑II, ‑III for narrative evolutions But this is optional — the core system stands without it.
