# **2. Templater Script — Auto‑Generate New Nodes**

This script creates a new file with:

- auto‑ID  
- auto‑timestamp  
- auto‑insertion of the Universal Node Template  

Put this in:

```
Templater User Scripts/
```

Name it:

```
newNode.js
```

Contents:

```javascript
module.exports = async (tp) => {
    const id = tp.date.now("YYYYMMDDHHmmss");
    const stamp = tp.date.now("YYYY-MM-DD HH:mm:ss");
    const title = await tp.system.prompt("Node Title");

    const file = await tp.file.create_new(
        `# ${title}

**ID:** ${id}  
**Created:** ${stamp}  
**Type:**  

## Summary

## Core Properties
- Identity  
- Resonance  
- Drift  
- Pressure  
- Collapse  
- Reintegration  

## Links
- [[Node Dynamics]]
- [[System]]
- [[Fib Flower]]
- [[Echo]]
- [[Pressure System]]
- [[Drift System]]

## Diagram
\`\`\`mermaid
stateDiagram-v2
    [*] --> Init
    Init --> Active: start()
    Active --> Init: reset()
\`\`\`
`,
        `${title}.md`
    );

    return file;
};
```

This gives you a **one‑click node generator**.

# **3. Auto‑Sort Script — Sort Nodes by Type**

If you want Threshold to behave like a **self‑organizing organism**, this script sorts nodes into folders based on the “Type” field.

Put this in:

```
Templater User Scripts/sortNode.js
```

Contents:

```javascript
module.exports = async (tp) => {
    const type = await tp.system.prompt("Type (Creature, System, Realm, Signal, Node)");
    const folder = `01 ${type}s`;

    await tp.file.move(`${folder}/${tp.file.title}.md`);
};
```

Now you can run:

**Templater → Run User Script → sortNode**

And the file moves itself.

# **4. Mermaid Generator Script — Auto‑Insert a Diagram**

This script inserts a fresh Mermaid block into any file.

Put this in:

```
Templater User Scripts/addMermaid.js
```

Contents:

```javascript
module.exports = async (tp) => {
    const name = await tp.system.prompt("Diagram Name");

    const block = `
## ${name}
\`\`\`mermaid
stateDiagram-v2
    [*] --> A
    A --> B: transition()
    B --> A: return()
\`\`\`
`;

    await tp.file.insert(block);
};
```

Now you can generate diagrams on demand.

# **5. How to Use These Scripts**

### **Step 1 — Enable Templater**
Settings → Community Plugins → Templater → Enable

### **Step 2 — Set Template Folder**
Settings → Core Plugins → Templates → Template Folder Location:

```
00 System/Templates
```

### **Step 3 — Add User Scripts Folder**
Settings → Templater → User Scripts Folder:

```
Templater User Scripts
```

### **Step 4 — Restart Obsidian**
Templater needs a reload to detect new scripts.
