[[01 - System/Scaffolding/System Architecture]]

Overview The Creation Architecture defines how new elements enter Threshold through player choice. Creation is not freeform invention — it is a structural interaction with the existing node‑graph of the world. Every player choice resolves into one of three actions:

  1. Bring in an existing dot

  2. Create a new dot

  3. Connect to an already‑connected dot These three actions form the entire logic of world expansion.

  4. Bring In an Existing Dot Definition The player selects an option that corresponds to a node already present somewhere in the system. Behavior • The system locates the existing node • Pulls it into the current canvas • Creates a new edge from the active node → existing node Meaning This is recognition, not invention. The world already contained this element; the player has simply revealed it. Use Cases • Known species • Known environments • Known symbolic artifacts • Known emotional states • Known collapse vectors

  5. Create a New Dot Definition The player selects an option that does not exist anywhere in the system. Behavior • A new node is generated • It is named and placed according to canonical folder logic • The system links the active node → new node Meaning This is generation. The world expands because the player touched a conceptual edge. Use Cases • New species • New symbolic artifacts • New diagrams • New collapse phenomena • New emotional physics states

  6. Connect to an Already‑Connected Dot Definition The player selects an option that already exists and is already connected to something in the current canvas. Behavior • No new node is created • A new edge is drawn between two existing nodes • Hidden structure becomes visible Meaning This is relational revelation. The player uncovers a structural truth that was already present. Use Cases • Emotional physics • Collapse adjacency • Field interactions • Layer dependencies • Symbolic resonance

Why This Architecture Works Creation in Threshold is built on: • Nodes (entities, concepts, artifacts) • Edges (relationships, dependencies, interactions) • Choices (player agency) • Rules (system architecture) The player’s actions determine: • what becomes visible • what becomes connected • what becomes meaningful • what becomes real The system responds by: • spawning new nodes • revealing existing ones • connecting structural truths Creation = activation. Discovery = recognition. Meaning = structure.
