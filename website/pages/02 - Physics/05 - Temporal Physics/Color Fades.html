1. They’re not fades — they’re emotional transitions Journey doesn’t fade colors because the scene changes. It fades colors because the emotional state changes. Color = emotional temperature. When the Traveler: • gains height → colors warm • enters danger → colors desaturate • reaches safety → colors soften • approaches mystery → colors deepen It’s emotional logic, not visual logic. Threshold can use this for: • Alignment shifts • Drift states • Threshold State dissolves • Spirit animal emotional resonance

The fades are slow enough to feel, fast enough to notice Journey uses a very specific pacing: • 1.5–3 seconds for major transitions • 0.5–1 second for micro‑shifts • 0.2–0.3 seconds for emotional pulses This creates: • A sense of breath • A sense of continuity • A sense of presence Threshold can adopt the same timing curves for: • Environmental pulses • Spirit animal mood shifts • UI emphasis

  3. The fades are layered, not global Journey rarely fades the entire screen at once. Instead, it fades: • sky color • sand color • fog color • light intensity • rim light warmth • particle tint Each layer shifts slightly differently. This creates a living gradient, not a flat fade. Threshold can use this for: • multi‑layered environmental transitions • emotional gradients in rest zones • symbolic shifts in The Loom

  4. The fades follow motion, not time This is the secret. Journey ties color transitions to: • movement • camera drift • wind direction • height • proximity to emotional nodes Color is reactive, not passive. Threshold can use this for: • spirit animals changing color as they move • environments shifting as the player drifts • emotional physics that respond to motion

  5. The fades are musical Even when the music is quiet, the color transitions follow: • phrasing • cadence • breath cycles It’s choreography. Threshold already leans toward rhythmic motion — color can join that rhythm.
