Purpose Layer Integration Rules define how Layers interact when: • two Layers overlap • a Layer transition occurs • a Layer is invoked by a role, species, or signal • environmental or emotional pressure shifts the substrate • collapse or recovery forces a Layer change This file ensures that Layers behave predictably, coherently, and non‑contradictorily across the entire system. Layers are not “modes.” They are substrates — each with its own physics. These rules define how those substrates combine.

  1. Integration Principles There are five universal principles governing Layer interaction.

1.1 Substrate Priority When two Layers overlap, the dominant substrate is determined by:

  1. Pressure intensity
  2. Identity state
  3. Signal influence
  4. Environmental bias
  5. Role alignment Priority is not fixed — it is contextual.

1.2 Non‑Contradiction Layers cannot produce contradictory physics. If two Layers would generate incompatible outcomes: • the higher‑coherence Layer takes precedence • the lower‑coherence Layer becomes a modifier Example: Earth + Mist → Earth provides structure; Mist modifies perception.

1.3 Additive Drift Drift from multiple Layers adds, it does not cancel. • Air drift + Mist drift = accelerated diffusion • Ember drift + Stone drift = pulsed compression • Ethyl drift + Earth drift = stabilized expansion Drift is always combinatory.

1.4 Collapse Dominance During collapse, the collapse‑aligned Layer takes over. Examples: • Spiral collapse → Ember + Mist • Brittle collapse → Stone + Earth • Recursive collapse → Ethyl + Memory environments Collapse overrides normal Layer priority.

1.5 Recovery Reversal During recovery, the stabilizing Layer becomes dominant. Examples: • Stillwatch → Ethyl • Grove Pulse → Earth + Memory • Deep Quiet → Stone • Ember Rest → Ember (low‑heat variant) Recovery Layers override collapse Layers.

2.7 Air + Ethyl Motion + Stillness Produces: oscillation, rhythmic drift, patterned movement. Used for: • Listener role • patterned signals • drift synchronization

2.8 Mist + Ember Distortion + Heat Produces: volatile illusions, emotional distortion, spiral collapse. Used for: • Spiral Echo • collapse contagion • Trickster overload

2.9 Mist + Ethyl Distortion + Stillness Produces: quiet illusions, soft perception shifts, identity reflection. Used for: • deep forests • ruins • memory environments

2.10 Ember + Ethyl Heat + Stillness Produces: warm recovery, emotional re‑centering, collapse softening. Used for: • Ember Rest • emotional stabilization • post‑collapse recovery

  1. Multi‑Layer Integration (Triads) Triads occur when three Layers combine. They follow these rules: 3.1 Dominant Layer sets the substrate 3.2 Secondary Layer modifies drift 3.3 Tertiary Layer modifies identity Example: Earth + Mist + Ethyl → • Earth = substrate • Mist = drift curvature • Ethyl = identity stabilization Triads are used for: • complex environments • advanced signals • species adaptations • collapse patterns

Layer Switching Rules Layer switching occurs when: • pressure shifts • identity shifts • role shifts • signal influence • environmental bias • collapse or recovery Switching follows: 4.1 Threshold Rule A Layer only switches when pressure exceeds identity tolerance. 4.2 Drift Momentum Rule High drift momentum accelerates switching. 4.3 Signal Override Rule Signals can force a Layer switch. 4.4 Collapse Rule Collapse forces a switch into collapse‑aligned Layers. 4.5 Recovery Rule Recovery forces a switch into stabilizing Layers.
