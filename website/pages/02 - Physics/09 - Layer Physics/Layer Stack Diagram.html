Layer Stack Diagram

The Layer Stack Diagram is the canonical visual representation of the seven‑Layer physics architecture of Threshold.
It depicts the vertical ordering, density gradients, permeability shifts, and collapse adjacency across the full stack.

Layers are arranged from highest permeability to deepest density, forming a coherent physics gradient.

Vertical Ordering (Top → Bottom)

  1. Air Layer — motion, intention, vector flow
  2. Mist Layer — permeability, drift, emotional bleed
  3. Glass Layer — exposure, amplification, vulnerability
  4. Ethyl Layer — symbolic curvature, encoded meaning
  5. Stone Layer — structure, containment, integrity
  6. Root Layer — memory density, emotional weight
  7. Ash Layer — fracture, residue, collapse adjacency

This ordering reflects:

  • decreasing permeability
  • increasing density
  • increasing collapse risk
  • deeper memory compression
