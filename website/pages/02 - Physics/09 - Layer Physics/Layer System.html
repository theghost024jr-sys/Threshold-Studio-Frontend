Purpose The Layer System defines the six fundamental physics substrates of Threshold. Each Layer is a complete physical regime with its own: • motion rules • identity behavior • collapse tendencies • signal expression • environmental influence • role bias Layers are not “elements” or “biomes.” They are ontological substrates — the physics the world runs on. This file defines the system as a whole. Individual Layer files define each substrate in detail.

  1. The Six Layers Threshold contains six canonical Layers, each representing a distinct physics substrate: • Air — motion, acceleration, pursuit • Earth — stability, grounding, structure • Ember — heat, expansion, emotional ignition • Ethyl — stillness, compression, identity coherence • Mist — distortion, ambiguity, perception drift • Stone — density, pressure, brittleness, collapse thresholds Each Layer is complete and self‑consistent. Together, they form the Layer Stack.

  2. Layer Stack Structure Layers are arranged in a non‑hierarchical stack. There is no “top” or “bottom.” Instead, each Layer occupies a position in conceptual space defined by: • drift behavior • identity behavior • collapse behavior • resonance pairs • interaction patterns The stack is designed to be: • modular • non‑circular • expandable • stable under pressure
