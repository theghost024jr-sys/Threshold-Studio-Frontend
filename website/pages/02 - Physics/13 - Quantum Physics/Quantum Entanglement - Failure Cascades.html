How entangled structures collapse under stress Failure cascades occur when an entangled element exceeds its tolerance threshold, forcing its partner(s) into a misaligned collapse phase. Because entanglement is non‑local, the cascade does not travel through corridors — it jumps instantly. There are four primary cascade types, each with its own signature.

  1. Mirror Collapse Cascade When one side collapses and forces the partner into its paired pathology This occurs in bindings like QE‑003 (Fracture–Containment Mirror). Trigger: One element enters its collapse state. Propagation: Partner is forced into the mapped collapse state, even if local conditions don’t justify it. Example: • Shatter Zone → Fracture Bloom • Stone Basin → Pressure Cascade (forced overload) Signature: Collapse spreads as paired opposites, not copies. Risk: If both collapse states amplify each other, the cascade becomes recursive.

  2. Counterweight Inversion Cascade When a balancing pair flips polarity and destabilizes both sides This occurs in bindings like QE‑001 (Depth–Momentum Counterweight). Trigger: One parameter spikes beyond the binding law. Propagation: The partner is forced into an inverse collapse state. Example: • Quiet Grove → Quiet Lock • Plains → Drift Runaway (forced acceleration) Signature: A seesaw effect: one sinks, the other shoots upward. Risk: If the counterweight flips too fast, the system enters temporal whiplash.

  3. Phase Mismatch Cascade When entangled elements fall into different temporal phases This occurs in bindings like QE‑004 (Loop–Exit Entanglement). Trigger: One side enters Propagation while the other is still in Amplification. Propagation: Temporal phases desynchronize, causing: • loop tightening • anchor overload • temporal tearing Example: • Recursive Hollow → Recursive Collapse • Grove → Quiet Lock (anchor collapse) Signature: Collapse spreads as temporal misalignment, not structural failure. Risk: If the mismatch persists, the system loses temporal coherence.

  4. Rigidity Cascade When elasticity collapses and forces rigidity across the entangled network This occurs in bindings like QE‑103 (Elasticity–Freeze Binding). Trigger: Elasticity Chamber flex_index → 0. Propagation: Deep Ice is forced into Freeze‑Twist Lock, which then forces: • Drift corridors to seize • Pressure mesh to stiffen • Resonance web to crystallize Signature: Collapse spreads as system-wide freeze, not localized failure. Risk: This is the most dangerous cascade — it can lock the entire Field Body.

  5. Multi‑Binding Cascade (Compound Failure) When one failure triggers multiple entanglements simultaneously This is the catastrophic mode. Trigger: A collapse in one node violates multiple binding laws at once. Propagation: Each entanglement fires its own cascade: • Mirror collapse • Counterweight inversion • Phase mismatch • Rigidity cascade Example: Recursive Hollow collapse can simultaneously: • overload Grove (QE‑004) • destabilize Plains (QE‑001) • stiffen Deep Ice (QE‑103) Signature: A network-wide collapse storm. Risk: Only the Time Organ can stop this — if it’s still functional.
