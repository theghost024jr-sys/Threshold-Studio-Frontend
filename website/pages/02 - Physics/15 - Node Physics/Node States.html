Three States of Unconnected Dots

  1. Latent (Dormant) • These dots exist in the system but are not yet active. • They represent potential — a species, biome, artifact, or emotional state that hasn’t been chosen yet. • They will be discovered when the player selects an option that matches them. Example: A dot labeled “Glass‑Winged Lurker” floats alone. If the player chooses “a creature with translucent wings,” the system connects to it.

  2. Unanchored (Awaiting Connection) • These dots were created but not yet structurally placed. • They need a parent node, field, or layer anchor. • They are waiting for you to decide where they belong. Example: You created “Collapse Echo” but haven’t linked it to Collapse Architecture or a biome. It floats until you connect it.

  3. Orphaned (Structural Violation) • These dots were placed incorrectly — wrong layer, wrong direction, or broken reference. • The system refuses to connect them. • They need to be repositioned, renamed, or collapsed. Example: A symbolic artifact placed inside a species folder. The canvas rejects the link.

How to Know Which Is Which Use this quick diagnostic:

System Response to Unconnected Dots • Canvas will not auto‑connect • Canvas will not delete them • Canvas will wait for activation This is why your canvases feel alive — they’re holding readiness.

What You Can Do If you want to clean up: • Run a Latent Node Sweep — identify all dormant dots and tag them with • Create a Connection Protocol.md file to define how and when dots get linked • Use Canvas Suppression Logic.md to collapse orphaned or invalid nodes • Generate a Discovery Index.md to track which dots are waiting for player activation
