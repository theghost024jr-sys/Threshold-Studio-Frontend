PURPOSE OF ENVIRONMENTAL CYCLE MAPPING Environmental Cycle Mapping answers three questions: • Where in the environment is the Cycle currently strongest • How the Cycle is shifting across space • When the next phase will emerge It is not prediction. It is pattern recognition. The Field breathes. Mapping shows where the breath is landing.

  2. THE FIVE PHASES AS ENVIRONMENTAL SIGNATURES Each phase leaves a distinct signature in the environment. These signatures are the basis of all mapping.

Mapping begins by identifying these signatures in the field.

  1. THE THREE LAYERS OF ENVIRONMENTAL MAPPING Environmental Cycle Mapping uses three diagnostic layers: A. Spatial Layer (Where) Tracks the location of each phase. Indicators include: • drift direction • flora patterning • path behavior • resonance gradients • light distribution B. Temporal Layer (When) Tracks the timing of phase transitions. Indicators include: • micro-season shifts • pressure accumulation • collapse onset signs • renewal sparks • void deepening C. Relational Layer (How) Tracks interactions between phases. Indicators include: • overlap zones • phase interference • hybrid environments • phase dominance shifts Together, these layers form the full map.

  7. CYCLE FLOW MAPPING — HOW PHASES MOVE ACROSS SPACE Cycle flow mapping tracks movement, not just location. Common flow patterns: • Circle → Gate: coherence saturates, pressure forms • Gate → Crown: pressure breaks, collapse ignites • Crown → Tree: collapse exhausts, void deepens • Tree → Lantern: stillness warms, renewal sparks • Lantern → Circle: renewal stabilizes, coherence returns Mapping these flows reveals the breathing pattern of the environment.

  8. HYBRID ZONES — WHERE PHASES OVERLAP Some environments express more than one phase simultaneously. Examples: • Circle + Gate: stable but tightening • Gate + Crown: volatile fracture zones • Crown + Tree: softening into stillness • Tree + Lantern: thawing void • Lantern + Circle: early coherence Hybrid zones are crucial for predicting transitions.
