# Pressure vectors

Pressure in Threshold is not a mood—it’s a **force field** acting on nodes, hinges, and canvases.

It shows up as **vectors**: directed pushes that shape collapse, drift, shear, and flow.

---

## 1. Core idea

**Pressure vector:**  
A directed force applied to a moment/node/region that:

- increases collapse likelihood  
- distorts flow  
- amplifies tension  
- reorients stance or world state  

Pressure is always **from → to**.

---

## 2. Basic pressure vector types

### A. Collapse vector

- **From:** outer ring / environment  
- **To:** hub / throat / core  
- **Effect:** pulls nodes inward, tightens edges, forms Hourglass or Hub.

```text
[Outer Rim]  →→→  [Core Cluster]
   Drift          Collapse

B. Drift vector

  • From: core / hub

  • To: outer rim / halo

  • Effect: pushes low‑mass nodes outward, creates Flower / Fib Flower ring.

text

[Core]  →→→  [Outer Rim]
 Anchor       Swim / Drift

C. Shear vector

  • From: player hinge

  • To: world hinge

  • Effect: misalignment, jump, reconfiguration of layout.

text

[Player Hinge] ↗
                X  ← [World Hinge]
           Shear / Snap

D. Resonance vector

  • From: identity / memory / meaning source

  • To: specific node or cluster

  • Effect: amplifies echo, keeps a region “lit” longer.

text

[Meaning Source]  →→→  [Resonant Cluster]
      Echo                 Glow / Hold

3. Pressure vector fields

Pressure rarely acts on a single node—it acts as a field.

Hub field

  • Many collapse vectors pointing inward.

  • Creates Hub or Hourglass throat.

  • High tension, high mass.

text

→ → → [HUB] ← ← ←

Flower field

  • Collapse vectors inward, drift vectors outward.

  • Core stabilizes, petals oscillate, rim swims.

  • This is the Threshold Flower.

text

   Drift →   [Petals]   ← Drift
             [Hub]
Collapse ←             → Collapse

Fib Flower field

  • Drift vectors arranged in spiral.

  • Outer rim swims in counter‑flow.

  • Petals grow along Fib progression.

text

Spiral Drift →  →  →  (Fib ring)
Core stable      Hub

4. Pressure vectors in 24‑Game

Map 24‑Game states to pressure behavior:

  • Stillness: minimal vectors, Static Canvas.

  • Motion: mild drift vectors, Dynamic Canvas.

  • Pressure: strong collapse vectors, Tension Canvas.

  • Echo: resonance vectors, Resonance Canvas.

  • Orientation: directional vectors, Navigation Canvas.

  • Commitment: hinge shear vectors, Choice Canvas.

  • Entity Contact: mixed collapse/resonance, Encounter Canvas.

  • Transition: stacked shear + collapse + drift, Threshold Canvas.

5. Practical usage

  • To create a Hub: increase inward collapse vectors, reduce outward drift.

  • To create a Flower: keep a stable hub, add outward drift + mild inward collapse.

  • To create an Hourglass: strong collapse into a narrow throat, then drift out.

  • To create a Fib Flower: apply spiral drift vectors to low‑mass outer nodes.

Pressure vectors are how you shape the moment’s geometry— they’re the invisible hands behind Flower, Hub, Hourglass, and Fib Flower flow.
