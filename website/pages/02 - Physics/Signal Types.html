Signal Types

Category: 06 – Mind Color: #FF4DA6 (Identity Pink) Role: Defines the four fundamental behavioral emissions that shape perception, action, drift, and alignment across all layers of Threshold.

Signal Types are behavioral primitives — the base‑state signals that determine how an entity moves through cognition. They are not personalities, roles, or archetypes. They are engines.

Every entity expresses a:

  • Primary Signal

  • Secondary Signal

  • Latent Signal

These three determine stability, drift behavior, and alignment.

The Four Canonical Signal Types

1. Guide

Essence: Orientation, coherence, forward‑vector Signature:

  • stabilizes attention

  • reduces drift

  • increases clarity

  • creates navigable pathways

Common Expressions:

  • teaching

  • pattern‑revealing

  • boundary‑mapping

Signal Type Mechanics

Primary Signal

The dominant behavioral emission. Defines default cognitive posture.

Secondary Signal

Modulates the primary. Defines how the primary expresses under load.

Latent Signal

Emerges only under:

  • drift

  • pressure

  • collapse

  • threshold events

Latent signals reveal true alignment.

Interaction With Layers

Signal Types express differently depending on substrate:

  • Air → clarity, orientation

  • Mist → ambiguity, inversion

  • Stone → structure, resistance

  • Ember → ignition, acceleration

  • Ethyl → dissolution, recombination

  • Earth → grounding, stabilization

Interaction With Drift

Signal Types determine:

  • how drift begins

  • how drift spreads

  • how drift resolves

Drift Profiles:

  • Guide → over‑clarity, rigidity

  • Trickster → fragmentation, incoherence

  • Warden → over‑containment, stagnation

  • Catalyst → runaway escalation
