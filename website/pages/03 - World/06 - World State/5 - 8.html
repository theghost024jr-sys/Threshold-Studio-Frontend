[[02 - Physics/18 - Worldstate Physics/Worldstate Map]] [[Threshold Map|Threshold Map]] What Extending from 5 → 8 Actually Means A 5‑petal wheel is: • asymmetrical • directional • inherently narrative • built around tension and return • always leaning toward the hub An 8‑petal wheel is: • symmetrical • stable • modular • capable of parallel processes • able to host multiple simultaneous states You’re shifting from: a story wheel → a system wheel. This is a real evolution.

The Core Rule Still Holds You said it earlier, and it’s still true: The petal pushes you back to the hub — not time, not stats. That rule survives the expansion. But with 8 petals, the way the pushback works becomes more nuanced.

The New 8‑Petal Structure Here’s the clean, canonical version:

  1. Petal 1 — Volatility The original tension point. Still the entry into instability.

  2. Petal 2 — Drift Movement without direction. The soft destabilizer.

  3. Petal 3 — Collapse Weather Environmental pressure. The world’s emotional climate.

  4. Petal 4 — Resonance Signal amplification. Where meaning gets louder.

  5. Petal 5 — Inversion The original “fifth path.” The flip, the mirror, the unexpected angle. These five are the original wheel. Now we add the new three.

  6. Petal 6 — Saturation When the system becomes “too full.” This is where your new mechanic lives: • too many players • too much attention • too much emotional weight Saturation triggers hub return. This is the petal that protects the system.

  7. Petal 7 — Clarity This is where Sapheen lives. Environmental Entities operate here. Clarity is: • perceptual stabilization • noise reduction • context restoration This petal prevents collapse by making the environment readable.

  8. Petal 8 — Reconciliation The final petal before the hub. Not “resolution,” but alignment. This is where: • the environment • the player • the system • the emotional physics …all line up just enough to allow a clean return. This is the “exhale” before the hub.

The Wheel Now Has a New Rhythm With 8 petals, the cycle becomes: Instability → Drift → Pressure → Resonance → Inversion → Saturation → Clarity → Reconciliation → Hub It’s smoother. More modular. More systemic. Less narrative. More Threshold.
