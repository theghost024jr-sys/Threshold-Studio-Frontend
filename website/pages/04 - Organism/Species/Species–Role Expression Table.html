00 Meta Systems — Species Architecture / Roles Layer The Species–Role Expression Table defines how each Species manifests, embodies, or distorts the Archetypal Roles when acting through them. Where the Species–Role Sense Table describes perception, this table describes expression — the outward behavioral pattern produced when a Species channels a Role. Expression is shaped by: • species instinct • emotional resonance • elemental alignment • identity drift • environmental curvature • signal distortion This table is the behavioral blueprint for how Roles appear in the world.

Purpose This file establishes: • the expression pattern each Species uses for each Role • the strengths and weaknesses of each Species–Role pairing • the drift tendencies unique to each pairing • the environmental modifiers that alter expression • the collapse risks associated with misalignment • the gifts unlocked when expression is stable It is the operational map for understanding how identity becomes action.

Expression Levels Each Species expresses Roles at one of four canonical levels:

  1. Aligned Expression • natural fit • stable behavior • low drift • high clarity • strong gift potential
  2. Functional Expression • competent but not intuitive • moderate drift • predictable behavior
  3. Strained Expression • forced or unnatural • high drift • distortion likely • collapse risk under pressure
  4. Shadow Expression • inversion or misalignment • unstable behavior • collapse or threshold events likely These levels mirror the emotional physics of the system.
