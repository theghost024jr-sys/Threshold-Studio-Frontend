THE TREE IN PLAIN LANGUAGE (CLEAN + STRUCTURAL)

STEP 1 — Receptivity Check

Can the orphan hear the presence of nearby nodes?

If no, the player must:

  • lower noise

  • align rings

  • open resonance

  • stabilize identity

If yes, move to Step 2.

STEP 2 — Brittleness Check

Can the orphan hold a link without snapping?

If no, the player must:

  • reduce tension

  • reduce shear

  • stabilize the node

  • anchor temporarily

If yes, move to Step 3.

STEP 3 — Proximity / Capture Radius Check

Is the orphan close enough to another node or chain?

If no, the player must:

  • drag the orphan

  • drag the chain

  • rotate the Flower

  • create a pressure gradient

  • trigger collapse drift

If yes, move to Step 4.

STEP 4 — Automatic Link Formation

If receptivity is high, brittleness is low, and proximity is achieved:

The system forms the link automatically.

No button. No prompt. No “connect” action.

Just physics.

THE CLEAN FORMULA BEHIND THE TREE

A link forms when:

Rn−Bn>0

and

d(Xorphan,Xtarget)<rcapture

Player actions modify Rₙ, Bₙ, or d().
