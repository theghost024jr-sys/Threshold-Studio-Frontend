1. Atomic Components Glyph Classes • Stroke — direction, intent, stance • Arc — emotional curvature, drift, permeability • Knot — compression, intensity, charge • Aperture — openness, void, receptivity • Anchor — grounding, fixation, stability • Vector — movement, pressure, transition

  2. Pressure Channels Primary • Inward — collapse, introspection, density • Outward — expansion, assertion, projection • Lateral — negotiation, balance, tension • Rotational — churn, transformation, reorientation Modifiers • Soft — atmospheric, tonal • Hard — decisive, structural • Diffuse — ambient, field‑based • Focused — targeted, precise

  3. Orientation Semantics • Vertical — stance, integrity, grounding • Horizontal — rest, continuity, drift • Diagonal — instability, motion, transition • Radial — centering, dispersal, resonance

  4. Spacing Rules • Tight — urgency, compression, intensity • Loose — spaciousness, drift, openness • Overlap — entanglement, fusion, shared pressure • Isolation — clarity, singularity, emphasis

  5. Composition Patterns Glyph → Seal • Combine 3+ glyphs • Must form a stable relational geometry • Pressure channels must either align or intentionally contrast Seal → Script • Linear or radial sequence • Encodes process, drift, or state change • Directionality matters (L→R, top→bottom, or radial outward) Script → Diagram • Spatialized relationships • Uses zones, vectors, apertures, and pressure fields • Meaning emerges from layout, not content
