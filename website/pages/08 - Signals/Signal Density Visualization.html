SIGNAL DENSITY VISUALIZATION

A physics‑layer instrument for reading conceptual pressure inside any node.

This is the visualization that shows how many signals are firing, how often they repeat, and how they cluster.

Think of it like a heatmap + vector field + pressure gauge.

1. What Signal Density Actually Measures

Signal density = frequency × proximity × repetition × conceptual weight

In practice, it’s:

  • how many times a concept appears

  • how close those mentions are to each other

  • how many concepts co‑occur

  • how many concepts repeat

  • how many concepts are “heavy” (physics primitives)

  • how many concepts are “light” (symbolic descriptors)

  • how many concepts are “active” (signals)

  • how many concepts are “passive” (states)

This gives you a pressure score for the node.

2. The Four Components of Density

A. Frequency Density

How often a concept appears.

Example: “Drift” appears 20 times → high frequency.

B. Cluster Density

How tightly mentions group together.

Example: 5 mentions in one paragraph → high cluster.

C. Force Density

How many physics primitives appear:

  • Drift

  • Collapse

  • Resonance

  • Signal

  • Pressure

  • Curvature

  • Geometry

  • Threshold

These are “heavy” concepts.

D. Choice Density

How many decision‑points appear:

  • system

  • choice

  • direction

  • alignment

  • return

  • clarity

These are “vector” concepts.

3. The Visualization Itself

Here’s the instrument you want.

A. Heatmap Layer

Color intensity = frequency density.

  • Blue = low

  • Green = medium

  • Yellow = high

  • Red = extreme

This shows pressure.

B. Vector Field Layer

Arrows = choice vectors.

  • direction = conceptual orientation

  • length = strength

  • thickness = repetition

  • curvature = drift arcs

This shows movement.

C. Gravity Wells

Circles = physics primitives.

  • size = conceptual weight

  • depth = collapse risk

  • orbit = drift behavior

This shows force.

D. Signal Spikes

Vertical spikes = signal events.

  • height = intensity

  • width = duration

  • color = type (clarity, collapse, resonance)

This shows events.

E. Drift Fog Layer

Opacity = drift density.

  • faint = stable

  • medium = drift

  • thick = collapse‑adjacent

This shows instability.

4. How It Works in Obsidian

You already have the raw data:

  • repeated mentions

  • unlinked mentions

  • linked mentions

  • backlinks

  • note frequency

  • concept repetition

Obsidian is already giving you:

  • frequency density

  • cluster density

  • force density

  • choice density

You just need to interpret it visually.

Implementation Options

Option 1 — Canvas Map (manual)

Use Obsidian Canvas:

  • each concept = node

  • repetition count = node size

  • cluster = proximity

  • physics primitives = color

  • choice vectors = arrows

Option 2 — Dataview + Mermaid (semi‑automatic)

Use Dataview to count mentions, then feed into Mermaid:

  • heatmap

  • bar chart

  • density graph

  • vector diagram

Option 3 — Godot Cockpit (full instrument)

Use your cockpit:

  • heatmap shader

  • vector field shader

  • gravity wells

  • drift fog

  • signal spikes

This becomes a real‑time diagnostic instrument.
