🌱 THE ROOT‑CARD MODEL (5 cards × 5 base attributes)

Each card begins with:

  1. Click Target
  2. Action
  3. Creation
  4. Linking
  5. Limiter

These are the root powers — the baseline permissions.

Then, as players contribute to the graph (by using their root powers), they unlock additional attributes that extend or mutate their card.

This gives you:

  • a simple starting point
  • a natural progression
  • emergent complexity
  • no need for turns
  • no need for GM oversight
  • a world that grows because players act

It’s perfect.

🔓 HOW UNLOCKING WORKS (the contribution mechanic)

You don’t need XP, points, or scoring.
You use the graph itself as the progression system.

A player unlocks a new attribute when they meet a simple condition like:

  • After 3 contributions
  • After linking 5 nodes
  • After creating 2 biomes
  • After filling 3 blank .md files
  • After touching 3 yellow PNGs

Each card can have its own unlock condition — or you can use a universal rule:

Every 3 contributions unlocks one new attribute on your card.

This keeps it clean.

🧩 THE FIVE ROOT CARDS (with their five base attributes)

Here’s the canonical 5×5 root set — the simplest, cleanest version:

CARD 1 — Yellow Operator (Root)

  1. Click Target: Yellow PNG
  2. Action: Open paired .md
  3. Creation: None
  4. Linking: .md → one layer
  5. Limiter: Only yellow PNGs

CARD 2 — Blank Filler (Root)

  1. Click Target: Blank .md
  2. Action: Add one sentence
  3. Creation: None
  4. Linking: None
  5. Limiter: Only .md with zero content

CARD 3 — Biome Spawner (Root)

  1. Click Target: Any image PNG
  2. Action: Spawn biome node
  3. Creation: One biome
  4. Linking: Biome → clicked PNG
  5. Limiter: Biome gets no other links

CARD 4 — Layer Binder (Root)

  1. Click Target: Any layer node
  2. Action: Select existing .md
  3. Creation: None
  4. Linking: .md → layer
  5. Limiter: Cannot edit .md content

CARD 5 — Connector (Root)

  1. Click Target: Any two .md files
  2. Action: Create one link
  3. Creation: None
  4. Linking: .md ↔ .md
  5. Limiter: Cannot touch images or layers

🌿 UNLOCKED ATTRIBUTES (the fun part)

Each card can unlock:

  • a second click target
  • a second action
  • a mutation of their root power
  • a new creation type
  • a new linking permission
  • a soft override of their limiter

For example:

Yellow Operator unlock:
“Now allowed to link .md → biome.”

Blank Filler unlock:
“Now allowed to add a second sentence.”

Biome Spawner unlock:
“Now allowed to link biome → one .md.”

Layer Binder unlock:
“Now allowed to create a sub‑layer.”

Connector unlock:
“Now allowed to remove one link per session.”

These are tiny, but they change the whole system.
