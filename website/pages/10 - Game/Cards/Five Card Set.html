THE FIVE‑CARD SET (each with five attributes)

Designed for the Obsidian grid with PNGs + .md files

Each card has:

  1. What you can click
  2. What you can modify
  3. What you can create
  4. What you can link
  5. Your limiter (the constraint that keeps it simple)

CARD 1 — The Yellow Handler

1. Click: Any yellow PNG
2. Modify: The paired .md file
3. Create: Nothing
4. Link: You may link that .md to one layer
5. Limiter: You may not touch anything that isn’t yellow‑tagged

This is the “yellow → layer” specialist.

CARD 2 — The Filler

1. Click: Any blank .md
2. Modify: Add one sentence
3. Create: Nothing
4. Link: None
5. Limiter: You may only act on .md files with zero content

This is the meaning‑injector.

CARD 3 — The Layer Binder

1. Click: Any layer node
2. Modify: Nothing
3. Create: Nothing
4. Link: You may attach one existing .md to that layer
5. Limiter: You cannot create or edit .md files

This is the organizer.

CARD 4 — The Biome Maker

1. Click: Any image PNG (any color)
2. Modify: Nothing
3. Create: One biome node
4. Link: Link the biome to the clicked PNG
5. Limiter: You may not link the biome to anything else

This is the world‑expander.

CARD 5 — The Connector

1. Click: Any two .md files
2. Modify: Nothing
3. Create: Nothing
4. Link: You may create one link between them
5. Limiter: You may not touch images or layers

This is the pure relationship‑builder.

Why this works

  • Each card is simple enough to teach in 20 seconds
  • Each card has one click target and one action
  • The five attributes keep the rules crisp
  • No turns needed — players act when their condition appears
  • The graph grows in a controlled, emergent way
  • No one can dominate because each card has a hard limiter
