Engine Glossary

Definitions of Core Runtime Terms in Threshold

This glossary defines all major Engine concepts used throughout Threshold. Every Organ, Chamber, Species, Humanoid, Glyph, and Map relies on these terms for consistent behavior.

Drift

The natural movement of nodes from high pressure to low pressure. Drift forms currents, flows, and migration paths. Drift speed is determined by Signal Strength; Drift direction is determined by Layer Alignment.

Pressure

The invisible field generated by Organs, Chambers, and Flowers. Pressure shapes Drift, determines stability, and creates gradients that push or pull nodes.

Resonance

Harmonic alignment between nodes. Resonance accelerates Drift, stabilizes clusters, and reduces Collapse risk. Resonant nodes form stable orbits.

Collapse

The failure state of node stability. Collapse occurs when Pressure exceeds a node's Stability Threshold. Collapse resets Drift direction and ejects nodes into Fault Lines.

Navigation

The decision-making layer that determines how nodes choose paths through Threshold. Navigation follows low-resistance routes and avoids high-pressure zones.

Role Gravity

The force that pulls nodes toward their intended function. Role Gravity stabilizes Drift, prevents runaway Collapse, and aligns nodes with compatible Organs.

Signal Strength

The intensity of a node's Drift potential. Higher Signal Strength increases Drift speed and Resonance sensitivity.

Layer Alignment

The orientation of a node within Threshold's layered structure. Alignment determines Drift direction and Resonance compatibility.

Stability Threshold

The maximum Pressure a node can withstand before collapsing. Species, Organs, and Chambers each have unique thresholds.

Fault Line

A path created by Collapse events. Fault Lines redirect nodes into new Drift routes and can trigger Organ-level reactions.

Cluster

A group of nodes held together by Resonance. Clusters stabilize Drift and reduce Collapse risk.

Gradient

A difference in Pressure between two points. Gradients generate Drift and define Navigation routes.

Flow Loop

The Engine's metabolic cycle:

Drift -> Pressure -> Resonance -> Collapse -> Navigation -> Role Gravity -> Drift

This loop governs all node behavior.

Organ Profile

A set of Engine parameters defined by an Organ:

  • Pressure Profile
  • Resonance Profile
  • Collapse Threshold
  • Navigation Map
  • Role Gravity Vector

Profiles determine how Organs interact with the Engine.

Chamber Profile

A localized Engine parameter set defined by a Chamber:

  • Local Pressure
  • Local Drift
  • Local Resonance
  • Local Collapse Risk
  • Local Navigation Path

Chambers express Organ behavior internally.

Blueprint

A diagram showing the structure of a force, system, Organ, or Chamber. Blueprints are automatically embedded by the gallery engine when referenced.

Map

A visual representation of Drift currents, Pressure gradients, Resonance clusters, or Collapse Fault Lines. Maps define Navigation and environmental behavior.

Core Node

The stabilizing heart of the Engine. The Core Node maintains harmonic rhythm and prevents systemic Collapse.

Boundary Membrane

The semi-porous skin surrounding the Engine. It regulates external Pressure, absorbs Drift, and protects internal Chambers.

Alignment Well

A Role Gravity structure that pulls nodes toward their intended function. Alignment Wells stabilize Drift and reduce Collapse risk.

Entropy Vent

A Collapse Chamber structure that releases unstable energy during Collapse events.

Pathway Lattice

The Navigation Chamber's internal routing structure. It determines how nodes choose Drift Paths.

Gradient Forge

The Pressure Chamber's internal structure that generates and shapes Pressure fields.

Harmonic Coil

A Resonance Chamber structure that amplifies frequency alignment between nodes.

Drift Basin

The Drift Chamber's intake structure that converts chaotic motion into directional flow.

Collapse Sink

A structure that absorbs unstable nodes and resets their Drift Vectors.

Role Vector

The directional pull of Role Gravity. Each node has a Role Vector that determines its functional alignment.

Resistance Map

A Navigation structure that shows which paths have high or low traversal cost.

Stabilization Membrane

A Resonance structure that prevents harmonic overload and reduces Collapse risk.

Pressure Break

A membrane that ruptures during Collapse, releasing built-up gradients.

Engine Skin

The outer membrane that protects the Engine and regulates external Drift and Pressure.
