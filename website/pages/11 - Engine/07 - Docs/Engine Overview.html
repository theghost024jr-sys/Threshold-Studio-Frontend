Engine Overview

The Threshold Engine governs every node through six forces:

  1. Drift moves nodes.
  2. Pressure shapes movement.
  3. Resonance aligns nodes.
  4. Collapse resolves instability.
  5. Navigation selects paths.
  6. Role Gravity restores functional alignment.

Every node repeats this lifecycle:

Drift -> Pressure -> Resonance -> Collapse -> Navigation -> Role Gravity -> Drift

The canonical behavioral contract is defined in [[EngineRules]].
