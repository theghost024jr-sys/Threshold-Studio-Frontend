Overview Global Images is the visual substrate of Threshold. It contains system‑level images that define the world’s structure, symbolic language, and foundational geometry. These images are not tied to any single zone, species, or environment. They express the global logic of the world: how it organizes itself, how it communicates meaning, and how its internal physics are visually encoded. This chamber holds the visual organs that other systems reference.

Purpose Global Images exists to: • provide canonical visual representations of structural systems • anchor symbolic glyphs used across multiple layers • support Threshold Map, Meta Systems, and Substrates • unify the world’s visual language • serve as reference material for future diagrams, UI, and narrative assets It is the visual backbone of the world.

Image Taxonomy Global Images contains two primary organ types:

  1. Structural Images These images express the architecture of Threshold’s systems. They include: • structural diagrams • system geometry • foundational shapes • world‑level schematics These images define how the world is built.
  2. Symbolic Glyphs These images express the symbolic language of Threshold. They include: • resonance glyphs • navigation ethics • world‑level symbols • metaphoric visual anchors These images define how the world communicates meaning.

Placement Rules A file belongs in Global Images if it: • expresses world‑level structure • encodes a global symbolic principle • is referenced by multiple systems • is not tied to a specific species, zone, or environment A file does not belong here if it is: • a species image • a zone‑specific image • an environment image • a local artifact or ritual object Those belong in their respective chambers.
