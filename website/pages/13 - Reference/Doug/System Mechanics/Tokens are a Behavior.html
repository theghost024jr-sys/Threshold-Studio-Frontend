⭐ TOKENS ARE A BEHAVIOR

Artifacts, glyphs, species residues, biome objects — any of them can become tokens when the system needs them to.

A token is not a category.
A token is a mode.

A thing becomes a token when it:

  • grants permission
  • has a cost
  • has a rule
  • has a use
  • has a consequence
  • is limited or consumable

That’s it.

So yes — artifacts can be tokens.
Glyphs can be tokens.
Dreamscape leaves can be tokens.
Luminid trails can be tokens.
Hub seeds can be tokens.
Even drift leaks can produce token‑like fragments.

Threshold is a hybrid world, so its objects behave in hybrid ways.

⭐ THE HYBRID MODEL (THE ONE THAT FITS YOUR SYSTEM)

Here’s the structure that matches your stance:

1. Formal Tokens

These live in a Tokens folder.
They have names, rules, and clear uses.

Examples:

  • Spirit Anchor Token
  • Path Token
  • Memory Token
  • Shimmer Fragment Token

These are the “clean physics” objects.

2. Emergent Token‑Like Objects

These are artifacts, glyphs, species residues, or biome objects that behave like tokens but aren’t formally categorized as such.

Examples:

  • A glyph that unlocks a sealed biome
  • A Luminid Trail that reveals hidden paths
  • A Dreamscape Leaf that allows dual‑action creation
  • A Drift Compass charge
  • A Hub Seed that can only be planted once

These are the “Threshold weirdness” objects.

3. Hybrid Objects

These are both artifact and token, or both glyph and token, depending on context.

Examples:

  • An artifact that consumes itself
  • A glyph that breaks after use
  • A species residue that activates an artifact
  • A biome object that grants a one‑time ability

These are the “James‑shaped” objects — the ones that bend the system without breaking it.
