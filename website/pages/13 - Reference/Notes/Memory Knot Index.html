Overview The Memory Knot Index catalogs all known forms of memory knots — the twisted, recursive structures created when memory, emotion, and collapse pressure bind together. A memory knot is not a blockage or a trauma metaphor. It is a literal structural phenomenon in Threshold’s memory‑physics: • memory folds • emotional compression • symbolic entanglement • collapse residue binding • recursive loops Memory knots determine how memory becomes stuck, loops, resurfaces, or transforms. This index defines the types, behaviors, and diagnostic signatures of all knots.

Core Knot Classes Memory knots fall into four primary classes, each with distinct physics.

  1. Soft Knots Formed by emotional saturation and symbolic blur. Characteristics: • diffuse edges • slow recursion • soft emotional charge • easy to untangle • common in Mist‑heavy environments Soft knots are the “fog knots” of memory.

  2. Sharp Knots Formed by fracture, rupture, or sudden collapse pressure. Characteristics: • tight, angular structure • high emotional charge • fast recursion • Shimmer fracture lines • difficult to unwind Sharp knots are the “shatter knots” of memory.

  3. Deep Knots Formed in long‑term memory under heavy symbolic density. Characteristics: • slow, heavy recursion • deep emotional weight • Stone resonance compression • stable but hard to access • often tied to narrative substrate Deep knots are the “bedrock knots” of memory.

  4. Recursive Knots Formed when memory loops back into itself. Characteristics: • self‑referential spirals • repeating emotional arcs • Drift‑driven looping • high symbolic density • collapse‑adjacent behavior Recursive knots are the “loop knots” of memory.

Knot Anatomy Every memory knot contains:

  1. Core Thread The original memory line.
  2. Emotional Binding The emotional charge that tightens the knot.
  3. Symbolic Wrap The meaning‑layer that twists around the core.
  4. Collapse Residue The pressure that locks the knot in place.
  5. Recursion Loop The repeating arc that keeps the knot active.

Knot Behaviors

  1. Tightening Occurs when: • emotional charge increases • collapse pressure rises • symbolic density spikes
  2. Loosening Occurs when: • emotional fields soften • Drift stabilizes • Shimmer curvature aligns
  3. Splitting A knot fractures into multiple smaller knots.
  4. Merging Two knots bind into a larger, more complex knot.
  5. Surfacing A knot rises toward the Memory Shoreline.
  6. Submerging A knot sinks into Deep Memory.
