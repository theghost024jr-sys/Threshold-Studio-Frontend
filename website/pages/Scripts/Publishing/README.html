Threshold publishing tools

Open Threshold Vault.code-workspace from the parent ThresholdVault folder.

Use Terminal > Run Task in VS Code:

  • Vault: Check metadata previews the number of notes that normalization would change.
  • Vault: Normalize metadata writes normalized YAML across vault Markdown files. It skips .obsidian, .trash, and Scripts.
  • Vault: Validate publish surface checks _publish only. This is the default build task (Ctrl+Shift+B).

Use npm.cmd run publish:audit --prefix Scripts/Publishing for a read-only coverage summary. Use npm.cmd run publish:audit-write --prefix Scripts/Publishing to rebuild _publish_candidates/ as a separate review surface. The audit ignores body-empty notes, excludes content already represented in _publish, collapses exact copies, and combines numbered or otherwise normalized filename variants into source-attributed drafts.

Use npm.cmd run vault:anchor-check --prefix Scripts/Publishing to verify that the tools are running from C:\Users\James Romeo\Threshold\ThresholdVault\theghost and inventory the canonical vault without writing or copying files.

Normalization enforces the publishing spine:

  • Notes in _publish receive publish: true and draft: false.
  • Notes outside _publish receive publish: false and draft: true.
  • Missing title, id, date, category, tags, and description fields are added.
  • Malformed YAML is reported and left untouched.

Run npm.cmd run metadata:check --prefix Scripts/Publishing -- --verbose from the vault root when you need the full list of proposed changes.
