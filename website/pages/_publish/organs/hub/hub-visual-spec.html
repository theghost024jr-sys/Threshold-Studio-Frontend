1. Identity

The Hub glyph represents the central organ of Threshold — the world’s mouth, index, and navigation brain.
It must visually express:

  • centrality
  • orbit
  • cycle
  • drift
  • pressure
  • adjacency
  • world-state

The glyph is not decorative.
It is a functional symbol.

2. Geometry Overview

The Hub glyph consists of five concentric rings, each representing a core system:

  1. Inner Core (Engine)
  2. Cycle Ring
  3. Biome Ring
  4. Chamber Ring
  5. Signal Halo

All rings must be:

  • circular
  • centered
  • evenly spaced
  • radially aligned

The glyph must be readable at:

  • 64px
  • 128px
  • 240px
  • 512px

3. Ring Specifications

3.1 Inner Core — Engine

  • Shape: Solid circle
  • Color: Neutral gray (#222)
  • Behavior: Pulses with cycle
  • Symbol: Minimal, no iconography
  • Meaning: Drift, pressure, world-state

3.2 Cycle Ring

  • Shape: Thin ring
  • Segments: 3 (early, mid, late)
  • Colors:
    • Early: #AAAAAA
    • Mid: #DDDDDD
    • Late: #FFFFFF
  • Behavior: Rotates slowly
  • Meaning: Temporal position

3.3 Biome Ring

  • Shape: Medium ring
  • Segments: 7 (house, garden, forest, deepforest, root, stone, shadow)
  • Colors:
    • House: #F4D03F
    • Garden: #E67E22
    • Forest: #A67C52
    • Deepforest: #556B2F
    • Root: #C0392B
    • Stone: #5D4037
    • Shadow: #000000
  • Behavior: Color shifts based on current biome
  • Meaning: Environmental context

3.4 Chamber Ring

  • Shape: Thick ring
  • Segments: Dynamic (adjacent chambers)
  • Colors: Neutral (#444)
  • Behavior: Expands/contracts based on adjacency
  • Meaning: Spatial proximity

3.5 Signal Halo

  • Shape: Outer glow
  • Color: White (#FFFFFF) at 10% opacity
  • Behavior: Flickers on signal warnings
  • Meaning: Distortions, environmental signals

4. Motion & Behavior

4.1 Pulse

The entire glyph must breathe subtly:

  • Scale: 1 → 1.03 → 1
  • Duration: 4s
  • Curve: ease-in-out

4.2 Cycle Rotation

Cycle ring rotates:

  • Early: 0.5°/s
  • Mid: 1°/s
  • Late: 2°/s

4.3 Signal Flicker

Halo flickers when:

  • warnings
  • distortions
  • environmental signals

Opacity: 10% → 40% → 10%

5. Composition Rules

5.1 Centered

All rings must share the same center.

5.2 Even Spacing

Ring spacing must be consistent:

  • Core → Cycle: 8px
  • Cycle → Biome: 12px
  • Biome → Chamber: 16px
  • Chamber → Halo: 20px

5.3 No Text

The glyph must contain no letters, no numbers, no icons.

5.4 No Gradients (except halo)

All rings use flat color.

6. File Requirements

6.1 Format

  • PNG
  • Transparent background
  • Square canvas

6.2 Sizes

Must export cleanly at:

  • 128×128
  • 240×240
  • 512×512

6.3 Color Profile

sRGB

7. Acceptance Criteria

hub.png is considered valid when:

  1. All five rings exist
  2. Colors match biome palette
  3. Cycle ring has three segments
  4. Chamber ring supports dynamic segmentation
  5. Halo flicker is visually distinct
  6. Glyph remains readable at 64px
  7. No text or icons appear
  8. Transparency is correct
  9. Center alignment is perfect
  10. No gradients except halo

8. Summary

The Hub glyph is a five-ring solar wheel representing:

  • engine
  • cycle
  • biome
  • chamber adjacency
  • signal activity

It must be:

  • centered
  • circular
  • segmented
  • flat-colored
  • haloed
  • pulsing
  • rotating
  • flickering

This is the canonical visual identity of the Threshold Hub.
