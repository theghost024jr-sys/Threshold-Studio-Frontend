1. Environments Are Phase‑Driven Every environment in Threshold is generated from a phase identity, not from theme or aesthetics. A space must declare: • Primary Phase (Gate, Signal, Fault, Drift, Anchor, Return, Burden) • Shadow Phase (optional, for collapse states) • Triad Influence (which engine shapes its behavior) • Role Influence (which archetype governs its interaction logic) This ensures every environment is structurally coherent.

  2. Geometry Follows Emotional Physics Geometry is not decorative — it expresses the phase. Global rules: • Edges = Gate • Patterns = Signal • Fractures = Fault • Softening = Drift • Mass = Anchor • Recombination = Return • Weight = Burden Shadow geometry is the collapsed version of the same logic.

  3. Lighting Is Behavioral, Not Aesthetic Lighting communicates the state of the environment. Global rules: • Directional = Opening • Rhythmic = Patterning • High‑contrast = Rupture • Diffuse = Dissolution • Warm/steady = Grounding • Swirling = Integration • Dim/heavy = Continuity Shadow lighting collapses into: • misleading • chaotic • violent • fading • frozen • broken • oppressive Lighting is always a signal, never just a mood.

  4. Environments Respond to Player Behavior Every environment has a primary interaction mode: • Gate → responds to approach • Signal → responds to attention • Fault → responds to pressure • Drift → responds to stillness • Anchor → responds to grounding • Return → responds to synthesis • Burden → responds to memory This is the global interaction logic.

  5. Every Environment Has a Collapse Threshold Collapse is not random — it’s governed by the Shadow Cycle. Global collapse triggers: • overload • misalignment • unresolved pressure • incorrect role interaction • triad imbalance When collapse occurs, the environment shifts into its Shadow Phase.

  6. Recovery Always Moves Forward Recovery does not reverse collapse. It re‑enters the Master Cycle at the next functional phase. Global recovery vectors: • False Gate → Signal • Noise Spiral → Fault • Destructive Rupture → Drift • Dissociation → Anchor • Rigidity → Return • Failed Re‑Entry → Burden • Immobilizing Weight → Gate This keeps the world moving.

  7. Environments Are Never Static Every environment has: • a stable state • a stress state • a collapse state • a recovery state These states are global and apply to all phases.

  8. Environments Are Layered Every environment is built from: • Geometry • Lighting • Behavior • Collapse Logic • Recovery Logic • Triad Influence • Role Influence This layering ensures consistency across the world.

  9. Environments Must Be Legible A player should always be able to tell: • what phase they’re in • whether the environment is stable or stressed • whether collapse is imminent • what the environment wants from them • how to move forward This is global readability.

  10. Environments Teach the System The world itself is the tutorial. Global rule: Every environment must teach one piece of the Threshold physics. • Gate teaches opening • Signal teaches patterning • Fault teaches rupture • Drift teaches dissolution • Anchor teaches grounding • Return teaches integration • Burden teaches continuity Shadow environments teach collapse and recovery.
