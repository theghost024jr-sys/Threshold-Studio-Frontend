Predictive models of how entangled collapse spreads through the system Cascade Simulation Maps (CSMs) are non‑spatial diagrams that show how collapse jumps across entanglements. They don’t follow geography — they follow binding laws. Each map simulates: • Trigger point • Binding activation sequence • Phase misalignment • Propagation pattern • Containment opportunities • Failure endpoints There are four canonical simulation maps, each corresponding to a cascade type.

  1. MIRROR CASCADE MAP Collapse spreads as paired opposites Trigger Node: Shatter Zone (Fracture Bloom) Propagation Path:
  2. Shatter Zone → Stone Basin (QE‑003)
  3. Stone Basin → Depth Chamber (QE‑102)
  4. Depth Chamber → Quiet Grove (QE‑001)
  5. Quiet Grove → Plains (QE‑001) Pattern:

[Fracture Bloom] ↓ [Pressure Cascade] ↓ [Recursive Collapse] ↓ [Quiet Lock] ↔ [Drift Runaway]

Interpretation: The system fractures, then overloads, then deepens too far, then locks and skims simultaneously. Containment Window: Between steps 2 and 3 — Stone Basin diffusion can break the chain.

  1. COUNTERWEIGHT INVERSION MAP Collapse spreads as polarity flips Trigger Node: Quiet Grove (Quiet Lock) Propagation Path:
  2. Quiet Grove → Plains (QE‑001)
  3. Plains → Wind Channel (QE‑005)
  4. Wind Channel → High Branch (QE‑005)
  5. High Branch → Momentum Chamber (QE‑101) Pattern:

[Quiet Lock] ↓ [Drift Runaway] ↓ [Vector Shear] ↓ [Drift Runaway+] ↓ [Linear Collapse]

Interpretation: Stillness becomes runaway motion, which becomes shear, which becomes collapse. Containment Window: Step 2 — stabilizing Plains prevents Wind Channel shear.

  1. PHASE MISMATCH MAP Collapse spreads through temporal misalignment Trigger Node: Recursive Hollow (Recursive Collapse) Propagation Path:
  2. Recursive Hollow → Grove (QE‑004)
  3. Grove → Depth Chamber (QE‑102)
  4. Depth Chamber → Stone Basin (QE‑102)
  5. Stone Basin → Elasticity Chamber (QE‑103) Pattern:

[Recursive Collapse] ↓ [Quiet Lock] ↓ [Recursive Collapse+] ↓ [Pressure Cascade] ↓ [Elasticity Failure] Interpretation: Loops tighten, anchors overload, depth collapses inward, pressure spikes, elasticity fails. Containment Window: Step 1 — Grove can absorb the recursion if stillness is intact.

  1. RIGIDITY CASCADE MAP Collapse spreads as system-wide freeze Trigger Node: Elasticity Chamber (Frozen Collapse) Propagation Path:
  2. Elasticity Chamber → Deep Ice (QE‑103)
  3. Deep Ice → Drift Corridors (indirect)
  4. Drift Corridors → Pressure Mesh
  5. Pressure Mesh → Resonance Web
  6. Resonance Web → Momentum Chamber Pattern:

[Frozen Collapse] ↓ [Freeze-Twist Lock] ↓ [Corridor Seizure] ↓ [Pressure Hardening] ↓ [Resonance Crystallization] ↓ [Linear Collapse]

Interpretation: Flexibility dies, cold spreads, corridors seize, pressure hardens, meaning crystallizes, momentum snaps. Containment Window: Step 1 — Thaw-Flow Recovery can stop the entire cascade.

  1. COMPOUND CASCADE MAP When multiple entanglements fire at once This is the catastrophic simulation. Trigger Node: Recursive Hollow (under high load) Propagation Path:
  2. Recursive Hollow → Grove (QE‑004)
  3. Recursive Hollow → Plains (QE‑001)
  4. Recursive Hollow → Deep Ice (QE‑103)
  5. Grove → Depth Chamber (QE‑102)
  6. Plains → Wind Channel (QE‑005)

  7. Deep Ice → Elasticity Chamber (QE‑103)

  8. Elasticity Chamber → Momentum Chamber (QE‑101)

Pattern:

      [Recursive Collapse]
      ↙       ↓       ↘

[Quiet Lock] [Drift Runaway] [Freeze-Twist Lock] ↓ ↓ ↓ [Recursive+] [Vector Shear] [Elasticity Failure] ↘ ↓ ↙ [Temporal Heartbreak]

Interpretation: Three collapse modes ignite simultaneously and converge on the Time Organ. Containment Window: Only one: Elasticity Chamber must survive. If elasticity holds, the system can recover. If elasticity fails, the system enters total temporal lock.
