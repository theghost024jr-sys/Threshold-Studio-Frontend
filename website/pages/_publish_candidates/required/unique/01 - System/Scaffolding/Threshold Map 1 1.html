Threshold Map

Purpose

Defines the structural, spatial, and phenomenological logic of the Threshold’s internal map.
Establishes how the six-zone ring, central aperture, and drift mechanics function as a coherent system.
Serves as the canonical reference for all map-related assets, transitions, and interactions.

Geometry

  • Six-zone radial ring arranged around a central aperture.
  • Each zone occupies a distinct angular segment with its own atmospheric signature.
  • The central aperture acts as the system’s orienting void: non-zone, non-lore, pure structural anchor.
  • Outer boundary: soft perimeter, non-literal edge, defined by perceptual fade rather than hard borders.
  • Inner boundary: clean, stable, canonical.

Drift Logic

  • Movement is governed by perceptual drift rather than physical traversal.
  • Orientation is relative, not absolute; the map stabilizes around the user’s stance.
  • Transitions occur through atmospheric shifts, not corridors or gates.
  • Drift vectors define how attention, intention, and emotional stance reposition the user within the ring.
  • The central aperture is non-navigable; it is a reference point, not a destination.

Relationship to Other Layers

  • World Map: Threshold Map sits beneath the world layer as an interior architecture.
  • System Architecture: Defines Threshold as a subsystem with its own physics and interaction rules.
  • Interface Architecture: The map acts as a navigational substrate for UI transitions and scene logic.
  • Earth Layer: Threshold overlays the Earth layer symbolically, not geographically.

Visual Substrate

  • Canonical PNG represents the six-zone ring and central aperture.
  • Visual motifs emphasize clarity, orientation, and atmospheric differentiation.
  • The map is illustrative, not literal; it conveys structure, not terrain.
  • Canvas file defines editable geometry, labels, and alignment.
