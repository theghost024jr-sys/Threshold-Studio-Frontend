Essence The Threshold Map is the spatial interface of the system — a living diagram that displays how meaning moves. It is not geography. It is behavioral topology: a map of pressure, drift, resonance, and signal interaction. Every node, pathway, and region represents a state of meaning, not a physical place.

  1. Core Principles 1.1 Nodes Represent Meaning States Each node is a stable point where: • signals accumulate • roles express • layers overlay • drift becomes visible Nodes are not locations — they are conditions. 1.2 Pathways Represent Transitions A pathway is a vector of change between two meaning states. Movement along a pathway is Drift. 1.3 The Map Is Layer‑Overlaid All six Layers (Air, Earth, Ember, Ethyl, Mist, Stone) overlay the map simultaneously. Each region has a dominant substrate that shapes: • behavior • drift • resonance • stability 1.4 The Map Responds to Signals Signals: • activate nodes • saturate regions • distort pathways • create temporary structures • collapse unstable zones The map is reactive, not static.

  2. Node Logic 2.1 Node Types Nodes fall into three categories: • Core Nodes — stable, high‑density meaning states • Peripheral Nodes — flexible, low‑density states • Transient Nodes — temporary states created by drift or overlays 2.2 Node Behavior Nodes can: • accumulate signals • resonate with layers • collapse under pressure • split into sub‑nodes • merge into composite nodes 2.3 The Central Node: Signal Map The largest dot on the grid. It is: • the hub of all signal activity • the “now” of the system • the integration point for all layers • the place where drift is most visible Everything eventually passes through the Signal Map.

  3. Pathway Logic 3.1 Pathways Are Behavioral Vectors A pathway is a direction of change, not a road. Pathways represent: • emotional movement • conceptual transition • drift direction • resonance flow 3.2 Pathway Stability Pathways can be: • stable • unstable • volatile • blocked • overlaid • collapsed 3.3 Pathway Distortion Distortion occurs when: • Ember ignites • Mist blurs • Ethyl dissolves • Stone resists • Air accelerates • Earth accumulates Each layer modifies pathway behavior differently.

  4. Drift Logic on the Map 4.1 Drift Appears as Movement Drift is visualized as: • movement between nodes • distortion of pathways • saturation of regions • temporary node creation 4.2 Drift Pressure Drift increases when: • emotional load rises • layer conditions shift • overlays activate • roles conflict • species resonance spikes 4.3 Drift Collapse When drift exceeds stability: • nodes collapse • pathways break • new nodes form • overlays intensify

  5. Layer Overlay Logic Each layer modifies the map: • Air — increases motion, creates currents • Earth — stabilizes, forms deep corridors • Ember — ignites, creates flare nodes • Ethyl — dissolves, creates soft boundaries • Mist — blurs, creates resonance fields • Stone — anchors, forms pressure nodes Regions of the map have dominant substrates.

  6. Map Regions The map contains: • Core Region — stable, high‑density meaning • Mid Region — transitional, mixed‑layer zones • Outer Region — volatile, drift‑heavy zones • Threshold Edge — liminal boundary of the system Each region behaves differently under pressure.

  7. Temporary Structures The map can generate temporary structures: • drift corridors • resonance pools • flare zones • ambiguity fields • pressure wells • collapse scars These appear and disappear based on system activity.

  8. Outputs The Threshold Map produces: • drift patterns • resonance signatures • node activation states • layer overlays • collapse events • emergent structures These outputs feed into: • Species behavior • Role expression • Signal Drift • Layer interaction • Myth Progress
