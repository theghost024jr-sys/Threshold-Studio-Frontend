Species Architecture

Species Architecture defines how spirit‑animal embodiments are structured, classified, and related within Threshold. A “species” is not a biological category but a symbolic archetype that can express multiple signal embodiments across layers, overlays, and variations.

This system ensures consistency, scalability, and clarity as new spirit animals are added to the constellation.

Purpose

Species Architecture provides:

  • A unified structure for organizing spirit‑animal families
  • A way to manage multiple image variations of the same archetype
  • A consistent naming convention for signals
  • A framework for cross‑species resonance and clustering
  • A stable backbone for the Signal Map

Species = archetype
Variant = specific embodiment
Image = terminal node

Core Structure

Each species has:

  1. Species Family Note
  2. One or more Variants
  3. One image per variant
  4. Independent metadata for each variant

  • Species overview
  • Core symbolic meaning
  • Behavioral logic
  • Resonance themes
  • List of variants
  • Cross‑species relationships
  • Links to all variant notes
