Purpose The Environment Layer defines the world‑level physics that govern place, pressure, and spatial behavior. It is the layer that determines how environments: • exert pressure • shape drift • influence collapse • create recovery zones • generate environmental signals • bias species behavior • anchor map geometry This layer is the container for all environmental nodes.

  1. Layer Behavior 1.1 Pressure Generation Environment produces pressure fields that affect: • drift speed • collapse thresholds • signal distortion • identity stability • role expression Each environment has a unique pressure signature (heat, cold, saturation, echo, canopy, etc.).

1.2 Spatial Curvature Environment determines how space: • bends • compresses • expands • stabilizes Curvature affects navigation, drift vectors, and collapse geometry.

1.3 Recovery Zones Environment defines where and how Recovery Zones form: • oases • shelters • groves • ruins • clearings • sanctuaries Recovery Zones reduce pressure and allow identity stabilization.

1.4 Collapse Style Each environment has a collapse style: • implosive • dispersive • recursive • echo‑bound • frost‑locked • heat‑shattered Collapse style determines how collapse manifests physically and behaviorally.

  1. Environment → Signal Interaction Environment does not produce Signals by default. It produces conditions under which Signals may emerge. Environmental Signals occur when: • pressure becomes behavioral • drift becomes patterned • collapse leaves residue • recovery creates stillness Examples: • Winter Crown • Heat Mirage • Flood Pulse • Ashfall These are Signals, not environments.

  2. Environment → Species Interaction Environment biases species behavior: • migration • dormancy • aggression • camouflage • resonance Species linked to an environment inherit: • pressure tolerance • collapse style familiarity • drift adaptation • signal interpretation bias

  3. Environment → Map Geometry Environment defines: • biome boundaries • drift corridors • collapse zones • recovery nodes • environmental transitions The Threshold Map reads the Environment Layer to determine world shape.
