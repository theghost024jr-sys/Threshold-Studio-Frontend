⭐ THE “ASK theghost” CARD

(working title — we can rename it if you want)

Card Type: Helper / Support

Rarity: Common (but powerful)

Use Limit: Single‑use per draw

Return: Goes back into the deck after use

Trigger: You have an ability but don’t know how to perform it

⭐ What the card does (simple version)

If you have an ability — like:

  • recolor a path
  • create a new node
  • link two notes
  • embed a file
  • create a canvas card
  • use a plugin
  • reorganize a folder
  • apply a tag
  • make a dataview query

…but you don’t know how to do it, you can play:

ASK theghost

“Explain how to perform the action I already have the ability for.”

Then the card returns to the deck.

⭐ Why this card matters

It solves a real gameplay tension:

  • Players earn abilities
  • But they may not know how to execute them
  • And the game is meant to teach Obsidian literacy
  • Without punishing players for not knowing the mechanics yet

This card becomes the bridge between:

  • ability
  • knowledge
  • execution

It keeps the game flowing instead of stalling.

⭐ Card Text (clean, game‑ready)

ASK theghost

Type: Helper
Effect:
Use this card when you have an ability but don’t know how to perform it.
Ask for a step‑by‑step explanation of the action.
After use, shuffle this card back into the deck.

Flavor:
“You already have the power. You just need the move.”

⭐ Rules Clarification

  • You must already have the ability unlocked
  • You cannot use this card to gain new abilities
  • You cannot use it to ask about unrelated Obsidian features
  • You can use it to clarify any step of an ability you own
  • After use, it returns to the deck (not discarded)

This keeps it fair, balanced, and educational.

⭐ Optional Variant: ASK theghost+

A rare version:

ASK theghost+

Effect:
Ask how to perform any Obsidian action, even one you don’t have the ability for.
After use, discard this card.

This is like a wildcard or “oracle” card.
