Essence A Recursive Hollow is an environment defined by looping geometry, self‑similar resonance, and inward‑folding space. It is a place where paths repeat with slight variations, where sound returns altered, and where identity risks echoing itself into smaller and smaller versions. A Recursive Hollow is not confusing. It is iterative. Environmental Physics • Visibility: Medium; shapes repeat with slight distortions • Sound Behavior: Echoes return modified, as if “answering” themselves • Pressure: Inward spiraling; subtle pull toward the center • Stability: Low; loops shift based on emotional state • Temperature: Cool, with pockets of warmer “iteration nodes” Field Dynamics • Movement loops unless intention is sharply defined • Emotional resonance repeats in diminishing cycles • Memory fragments appear in multiple places simultaneously • Light refracts into recursive patterns, like nested reflections Phenomena

  1. Loop Path A path that returns to its starting point with slight differences. Travelers often notice: • shifted objects • altered shadows • emotional déjà vu
  2. Hollow Echo A sound that returns changed — slower, higher, or layered. Used by Guides to detect loop boundaries.
  3. Iteration Node A point where the environment “resets” itself. Touching it can trigger: • memory recursion • emotional replay • sudden clarity or disorientation
  4. Fractal Drift Small, repeating versions of objects appear at the edges of vision. They vanish when approached.
