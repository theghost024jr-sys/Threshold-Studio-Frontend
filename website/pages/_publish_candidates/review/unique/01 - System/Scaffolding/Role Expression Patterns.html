00 Meta Systems — Roles Layer / Behavioral Layer Role Expression Patterns describe the characteristic ways each Archetypal Role manifests in behavior, posture, emotional stance, and interaction. Where the Archetypal Roles file defines the essence of each role, Role Expression Patterns define the visible expression — how the role moves, reacts, escalates, stabilizes, or distorts under different pressures. Expression Patterns are the bridge between identity, behavior, and signal physics.

Purpose Role Expression Patterns establish: • the baseline behavioral signature of each Role • the emotional posture and interaction style • the drift tendencies inherent to each Role • the environmental modifiers that shape expression • the species‑specific variations (via downstream tables) • the collapse vectors visible in early behavior This file is the behavioral blueprint for all Roles.

Expression Components

  1. Behavioral Posture The default stance or mode of action. Examples: directive, receptive, catalytic, protective, disruptive.
  2. Emotional Signature The emotional field the Role generates. Examples: clarity, intensity, ambiguity, grounding, volatility.
  3. Interaction Style How the Role engages others. Examples: guiding, witnessing, provoking, stabilizing, challenging.
  4. Drift Tendencies The predictable ways the Role bends under pressure. Examples: overexpression, inversion, displacement, fragmentation.
  5. Collapse Vector The shadow form the Role moves toward when overwhelmed. Examples: Guide → Misleader, Maker → Destroyer.
  6. Environmental Modifiers How each Layer alters expression. Examples: • Ember amplifies intensity • Mist increases inversion • Stone increases rigidity • Air increases dissipation
