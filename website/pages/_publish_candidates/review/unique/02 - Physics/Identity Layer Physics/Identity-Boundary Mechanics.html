A. Coherence — Aligned Boundaries Signature: smooth, strong, evenly defined Behavior: • drift converges inward • resonance harmonizes • load distributes evenly • roles align Boundaries act as stability anchors.

B. Tension — Rigid Boundaries Signature: hard, narrow, over‑defined Behavior: • drift compresses • resonance sharpens • load concentrates • roles brace Boundaries act as pressure vessels.

C. Collapse — Fractured Boundaries Signature: splintered, cracked, dissolving Behavior: • drift bursts outward • resonance diffuses • load fractures • roles unbind Boundaries act as release points.

D. Void — Soft Boundaries Signature: faint, permeable, low‑definition Behavior: • drift sinks • resonance mutes • load settles • roles rest Boundaries act as rest membranes.

E. Renewal — Forming Boundaries Signature: flexible, exploratory, re‑emerging Behavior: • drift spirals upward • resonance flickers • load redistributes • roles ignite Boundaries act as growth scaffolds.
