Migration Ecology

Invariant Anchor This module expresses how migration behaves when cohesion is under pressure. See: [[Invariant00 – Cohesion Under Pressure]]

Definition

Migration is the movement of nodes or clusters across pressure gradients within the Garden. It is not “travel.” It is cohesion redistribution driven by:

  • pressure imbalance

  • resonance attraction

  • contradiction repulsion

  • Flower‑scale currents

Migration is the Garden’s circulatory system.

Core Behavioral Laws

1. Migration follows pressure gradients

Nodes and clusters move:

  • from high pressure → low pressure

  • from contradiction → alignment

  • from unstable zones → stable basins

Migration is the Garden’s way of restoring equilibrium.

2. Migration destabilizes Flowers before stabilizing them

When migration enters a Flower:

  • contradictions spike

  • boundary clusters wobble

  • collapse thresholds drop

  • resonance patterns distort

But once pressure redistributes:

  • identity sharpens

  • roles strengthen

  • collapse risk decreases

Migration is both threat and medicine.

3. Migration creates collapse chains

Large migrations can trigger:

  • boundary collapse

  • mid‑layer drift

  • core destabilization

  • zone‑based failure

Collapse is not caused by movement — it is caused by pressure overload.

4. Migration forms new identity basins

When migrating clusters settle:

  • cohesion condenses

  • contradictions eject

  • new cores form

  • new Flowers emerge

Migration is the Garden’s speciation engine.

5. Migration is regulated by Flower resonance

Flowers influence migration by:

  • attracting aligned clusters

  • repelling contradictory ones

  • shaping migration currents

  • stabilizing or destabilizing pathways

Migration is the Garden’s resonance‑guided flow.

Migration Types (structural, not lore)

  • Pressure Migration — movement caused by pressure imbalance

  • Resonant Migration — movement toward compatible Flowers

  • Collapse Migration — movement triggered by structural failure

  • Identity Migration — movement toward stable identity basins

  • Signal Migration — movement guided by Flower‑scale signals

These types emerge from physics, not classification.

Behavior Across the Origin Cycle

Distortion

Migration becomes chaotic; pressure gradients fluctuate.

Drift

Migration increases; clusters slide across boundaries.

Field

Migration spreads; Flowers lose cohesion.

Collapse

Migration spikes; contradictions eject; zones fail.

Identity

Migration slows; new basins form.

Role

Migration aligns to directional cohesion.

Signal

Migration stabilizes; Flowers coordinate movement.

Summary Rule

Migration is pressure‑driven cohesion redistribution that:

  • follows gradients

  • destabilizes before stabilizing

  • triggers collapse chains

  • forms new identity basins

  • is guided by Flower resonance

Migration is the Garden’s circulatory metabolism.
