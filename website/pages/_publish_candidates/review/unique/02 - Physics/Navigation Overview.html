Navigation Overview

Category: 00 – Navigation Color: #FFD93D (Sunflower Gold) Role: Defines the core mechanics of movement inside Threshold — how an Actor interprets state, selects a path, transitions between layers, and recovers orientation after drift or collapse.

Navigation is not movement. Navigation is state‑reading + path‑selection + transition‑execution.

It is the organ that turns the world from “a space” into “a traversable system.”

2. Navigation Structures

Threshold navigation is built from six canonical structures:

1. Corridors

Linear, directional, low‑ambiguity paths. Used for clarity and forward motion.

2. Staircases

Vertical transitions between layers or states. Used for ascent/descent.

3. Platforms

Stable zones for orientation and decision‑making. Used for recovery and planning.

4. Basins

Low‑pressure pockets that collect drift. Used for emotional processing and reset.

5. Clearings

High‑visibility, low‑noise spaces. Used for re‑anchoring and recalibration.

6. Seams

Thin boundaries between states. Used for transformation and redefinition.

Link: [[Navigation Structures Index]]

3. Navigation Modes

Actors navigate in three modes, depending on pressure:

1. Soft‑Vector Navigation

Low pressure, high clarity. Movement follows gentle drift pull.

2. Sharp‑Vector Navigation

High pressure, high definition. Movement follows strong directional force.

3. Diffuse‑Vector Navigation

Low definition, high ambiguity. Movement follows emotional resonance.

Link: [[Navigation Modes]]

4. Navigation Signals

Navigation relies on four signal types:

  • Guide → clarity, orientation

  • Trickster → inversion, reframing

  • Warden → containment, boundary

  • Catalyst → acceleration, ignition

These signals shape how an Actor interprets the world.
