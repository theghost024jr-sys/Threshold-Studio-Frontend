Worldstate Drift Map

How drift behaves across astral, symbolic, emotional, memory, and scene layers

The Worldstate Drift Map describes how drift moves through all layers of the world simultaneously. Drift is the directional force that shapes symbolic weather, emotional tone, memory behavior, and spatial thresholds. It originates in the astral layer and propagates downward, but each substrate modifies it differently.

This map shows how drift flows, collapses, reorients, and stabilizes across the entire system.

Drift Across Layers

Astral Layer

The highest-altitude drift field.

  • long-range drift vectors
  • constellation motion
  • resonance tone direction
  • early indicators of seasonal shifts
  • precursor to symbolic drift changes

Astral drift is the world’s long-range orientation.

Symbolic Substrate

The primary expression of drift.

  • vector fields
  • spirals, fronts, vortices
  • turbulence and storms
  • density gradients
  • collapse and reorientation

Symbolic drift is the world’s “weather.”

Emotional Substrate

Drift expressed as tone and amplitude.

  • emotional directionality
  • volatility or quietness
  • resonance sharpness
  • amplitude spikes or drops

Emotional drift amplifies or dampens symbolic drift.

Memory Substrate

Drift expressed as lineage movement.

  • thread orientation
  • recursion loops
  • fragmentation or rebinding
  • activation or dormancy

Memory drift is slow but deeply influential.

Scene Substrate

Drift expressed as spatial behavior.

  • threshold movement
  • spatial gradients
  • environmental resonance
  • stability or distortion

Scene drift is the physical expression of drift.

Drift States

Zero Drift

  • no directional force
  • density compresses
  • emotional substrate quiets
  • memory intertwines
  • scene becomes rigid

This is the Winter Crown state.

Outward Drift

  • spirals expand
  • density rises
  • emotional substrate becomes porous
  • memory sorts
  • scene softens

This is the First Seed / Spring state.

Accelerated Drift

  • vectors lengthen
  • density peaks
  • emotional substrate becomes volatile
  • memory becomes passive
  • scene becomes dynamic

This is the Summer Expansion state.

Inward Drift

  • spirals collapse
  • density falls
  • emotional substrate stabilizes
  • memory activates
  • scene cools

This is the Autumn Shedding state.

Drift Failure Modes

Drift Collapse

Vectors lose orientation and fall inward.

  • density voids
  • turbulence spikes
  • traversal becomes unstable

Drift Scatter

Vectors point in incompatible directions.

  • storms form
  • emotional substrate destabilizes
  • memory fragments

Rotational Drift

Vectors spiral around a center.

  • vortices
  • recursion loops
  • spatial distortion

Drift Inversion

Direction flips suddenly.

  • symbolic weather reverses
  • emotional amplitude spikes
  • scene thresholds distort

These failures appear across layers at different speeds.

Drift Recovery Modes

Reorientation

Vectors regain direction.

  • symbolic weather stabilizes
  • emotional tone settles
  • memory threads reconnect

Spiral-Out Recovery

Drift expands gently outward.

  • density rises
  • emotional substrate warms
  • scene softens

Spiral-In Recovery

Drift collapses gently inward.

  • density compresses
  • emotional substrate quiets
  • memory thickens

Motion Smoothing

Drift becomes coherent across layers.

  • astral → symbolic → emotional → memory → scene

Recovery begins at altitude and moves downward.

Cross-Layer Drift Mapping

Astral → Symbolic

Astral drift sets the direction of symbolic drift.

Symbolic → Emotional

Symbolic drift determines emotional amplitude.

Emotional → Memory

Emotional drift influences memory activation.

Memory → Scene

Memory drift shapes spatial thresholds.

Scene → Astral (feedback)

Scene drift can anchor or distort astral motion.

Drift is a loop, not a one-way cascade.

Seasonal Drift Patterns

Winter

  • zero drift
  • inward curvature
  • compressed density

Spring

  • outward spirals
  • rising density
  • porous emotional tone

Summer

  • accelerated drift
  • peak density
  • volatile emotional substrate

Autumn

  • inward collapse
  • falling density
  • stabilizing emotional tone

Seasonal drift defines the world’s breath cycle.

Reading the Drift Map

To interpret drift across layers:

  • check astral vector direction
  • observe symbolic weather patterns
  • read emotional amplitude
  • examine memory thread orientation
  • look for scene threshold movement
  • compare to seasonal resonance

Drift is the world’s directional truth.
