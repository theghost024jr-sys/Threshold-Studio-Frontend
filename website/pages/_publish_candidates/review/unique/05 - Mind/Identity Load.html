  1. WHAT IDENTITY LOAD IS Identity Load is the total pressure an identity carries at any moment. It is composed of: • Phase Load (pressure from the current Cycle phase) • Role Load (pressure from active roles) • Emotional Load (felt intensity, internal strain) • Narrative Load (story weight, meaning density) • Environmental Load (external pressure from surroundings) • Memory Load (residual imprint from past phases) • Collapse Residue Load (unresolved fragments) Identity Load is the mass of selfhood.

  2. THE FIVE COMPONENTS OF IDENTITY LOAD Identity Load is not one thing — it is a composite. A. Structural Load The weight identity carries simply by existing. Determined by identity weight, boundaries, and flexibility. B. Phase Load The pressure exerted by the current Cycle phase. • Coherence → alignment pressure • Tension → compression pressure • Collapse → dissolution pressure • Void → stillness pressure • Renewal → ignition pressure C. Role Load Each role adds or removes load: • Gatherer → accumulates • Holder → compresses • Releaser → removes • Restorative → neutralizes • Initiator → redistributes D. Memory Load The imprint of previous cycles. • strong coherence memory → stabilizing • strong collapse memory → destabilizing • strong void memory → slowing • strong renewal memory → accelerating E. Residue Load Unresolved fragments from collapse or tension. Residue load is the heaviest form of load.

  3. HOW LOAD MOVES THROUGH IDENTITY Load is not static — it flows. A. Load Accumulation Load increases when: • boundaries harden • roles brace • drift compresses • resonance sharpens • environment densifies • memory resurfaces B. Load Distribution Load spreads across identity structure. • flexible identities distribute load evenly • rigid identities concentrate load • fragmented identities scatter load C. Load Release Load decreases when: • roles unbind • drift scatters • resonance diffuses • identity softens • environment rests Load is the pressure metabolism of identity.

  4. LOAD ACROSS THE FIVE IDENTITY STATES Identity Load behaves differently in each phase.

A. Aligned Identity (Coherence) Load: low to moderate Behavior: • load distributes evenly • identity stabilizes • roles align Identity is a load‑bearing structure.

B. Braced Identity (Tension) Load: high Behavior: • load concentrates • strain increases • boundaries harden Identity becomes a pressure vessel.

C. Dissolving Identity (Collapse) Load: unstable Behavior: • load fractures • residue forms • identity unbinds Identity becomes a load explosion.

D. Resting Identity (Void) Load: minimal Behavior: • load settles • residue sinks • identity empties Identity becomes a load basin.

E. Forming Identity (Renewal) Load: rising Behavior: • load redistributes • new structures form • roles ignite Identity becomes a load lattice.
