Threshold Toolkit — Core Tools for Building a Living Architecture

Threshold is not a static wiki — it’s a living organism built inside Obsidian. This toolkit defines every major capability you can use to construct, simulate, visualize, and evolve the world.

Each section includes:

  • What the tool is

  • What it’s good for

  • How Threshold uses it

  • Links to relevant nodes

  • Mermaid diagrams where appropriate

# **3. Dataview — Living Data Structures**

Dataview turns your vault into a **queryable database**.

Use it for:

- Creature indexes
    
- Realm lists
    
- Flower registries
    
- System dashboards
    
- Drift/pressure tables
    
- Auto‑generated catalogs
    

### **Example**

dataview

```
TABLE type, drift, pressure
FROM "Creatures"
WHERE drift > 5
SORT pressure DESC
```
