THE LOOP (formal definition)

A loop is a closed causal circuit in which:

  1. A state produces an output.
  2. That output re-enters the system as the next input.
  3. The system updates its state based on that input.
  4. The updated state produces a new output.
  5. The cycle repeats.

A loop is complete when no external intervention is required for any of those steps.

That’s the entire structure.
