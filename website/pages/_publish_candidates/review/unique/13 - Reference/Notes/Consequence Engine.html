Definition The Consequence Engine is the interpretive mechanism that applies vectors through invariants to produce motion within the Field. It determines how actions become outcomes, how force propagates, and how the Matrix updates in response to change. The Consequence Engine is not a judge. It is a translator of force into effect.

Purpose To ensure that every action, state change, or activation within the system results in: • a predictable consequence • a coherent transformation • a conserved motion • a resolved outcome The Consequence Engine guarantees that nothing in the system is inert.

Inputs The engine receives: • Vectors (directional forces) • Invariants (stabilizing laws) • Node States (current conditions of artifacts) • Field Context (zone, role, lineage, drift state) • Activation Events (gifts, crossings, neglect, invocation) These inputs determine how the engine interprets an action.

Process The Consequence Engine operates in four steps:

  1. Interpret Vector Identify which vector(s) are active: • Reciprocity • Lineage • Drift • Threshold • Gift • Role • Zone Each vector provides a directional rule.
  2. Apply Invariants Stabilize the vector through the invariants: • cost • transformation • identity • consequence • resolution • conservation Invariants constrain how the vector can behave.
  3. Generate Motion Produce the resulting motion: • propagation • transformation • feedback • drift accumulation or resolution • threshold crossing • role activation or collapse Motion is always conserved.
  4. Update the Matrix The Matrix of Force is updated to reflect: • new states • new tensions • new balances • new consequences • new available vectors The system remains coherent.

Outputs The engine produces: • State changes • New vector activations • Resolved or accumulated drift • Crossings or collapses • Reciprocal return paths • Updated lineage states • Zone‑specific effects Every output is conserved and interpretable.

Properties of the Consequence Engine Deterministic Given the same inputs, it produces the same outputs. Closed It requires no external adjudicator. Recursive Outputs can become new inputs. Conserved No motion disappears; it must resolve or propagate. Universal It applies to every artifact in the Field.

Function The Consequence Engine: • enforces the Binding Law • animates the Field • drives the Matrix • stabilizes motion through invariants • channels motion through vectors • ensures every action has consequence • maintains coherence across the entire system This is the operational core of the System of Force.

Relationship to Other Meta Files • Binding Law → declares universal participation • Field → provides the environment • Vectors → generate directional force • Invariants → constrain and stabilize force • Matrix of Force → maps all interactions • Consequence Engine → interprets and executes all interactions The Consequence Engine is the mechanism that makes the system move.
