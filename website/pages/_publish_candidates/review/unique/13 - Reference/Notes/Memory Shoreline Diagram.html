Overview The Memory Shoreline Diagram illustrates how memory behaves in Threshold as a tidal boundary between: • what is held • what is lost • what returns • what drifts • what resurfaces under pressure The shoreline is not a metaphor — it is a behavioral model of memory’s interaction with emotional physics, symbolic density, and narrative substrate. It shows how memory forms banks, tides, erosion zones, and exposure layers.

Purpose The diagram exists to: • map memory stability • show where memories accumulate • reveal how emotional tides shape recall • illustrate collapse‑driven erosion • explain resurfacing events • support Witness and Curator memory‑work • anchor memory behavior across systems It is the primary structural model for memory dynamics.

Core Components

  1. Shoreline The boundary between held memory and drifting memory. It shifts based on: • emotional charge • collapse pressure • symbolic density • narrative weight The shoreline is always moving.

  2. Tidal Zone Where memories move in and out of accessibility. Tides are driven by: • emotional tides • Drift currents • Shimmer curvature • collapse residue This is where resurfacing happens.

  3. Deep Water Long‑term, inaccessible, or dormant memory. Characterized by: • low visibility • high symbolic density • slow Drift • deep emotional weight Deep Water memories return only under specific conditions.

  4. Exposed Shelf When collapse or emotional intensity pulls the water back, revealing: • old structures • forgotten fragments • symbolic residue • unresolved arcs Exposure is temporary and destabilizing.

  5. Erosion Zone Where memories degrade due to: • collapse pressure • emotional overload • narrative fracture • Shimmer distortion Erosion does not delete memory — it alters it.

  6. Depositional Zone Where new memories accumulate. Shaped by: • emotional warmth • Stone resonance • Ethyl distribution • narrative coherence This is where stable memory forms.

Behavioral States High Tide Memory becomes soft, blurred, symbolic. Access decreases. Emotional charge rises. Low Tide Memory becomes sharp, exposed, sometimes overwhelming. Old fragments return. Storm Tide Collapse weather distorts the shoreline. Mass resurfacing or mass erosion. Still Water Memory stabilizes. Shoreline becomes predictable. Ideal for Witness work.

Environmental Interactions Drift Moves memory fragments along the shoreline. Mist Softens memory edges; increases symbolic drift. Shimmer Refracts meaning; alters interpretation of resurfaced memory. Stone Anchors stable memory; reduces erosion. Ember Ignites memory; accelerates resurfacing. Ethyl Distributes memory evenly; reduces clustering. Heat Raises emotional tides; increases volatility. Collapse Erodes, fractures, or exposes memory layers.

Use Cases • emotional processing • collapse recovery • Witness Spiral memory‑work • narrative reconstruction • symbolic interpretation • long‑term memory mapping • resurfacing event analysis The Memory Shoreline Diagram is the core tool for understanding how memory behaves under pressure.
