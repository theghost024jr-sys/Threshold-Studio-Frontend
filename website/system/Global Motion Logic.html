Overview Global Motion Logic defines the fundamental movement rules that govern all systems in Threshold. It is the underlying physics of: • phase transitions • collapse transitions • recovery transitions • environmental shifts • role activation • triad activation • sensory changes Everything moves according to the same universal pattern.

  1. The Three Universal Motion Types All motion in Threshold falls into one of three categories:

  2. Functional Motion Movement along the Master Cycle. This is aligned, coherent, phase‑appropriate motion.

  3. Collapse Motion Movement along the Shadow Cycle. This is inverted, distorted, phase‑misaligned motion.

  4. Recovery Motion Movement from a Shadow Phase back into the next Master Phase. This is forward re‑entry, not reversal. These three motions govern the entire system.

  5. Functional Motion (Master Cycle Motion) Functional motion always follows this sequence: Gate → Signal → Fault → Drift → Anchor → Return → Burden → Gate This motion is: • forward • coherent • stable • predictable • phase‑aligned Functional motion is the default physics of Threshold.

  6. Collapse Motion (Shadow Cycle Motion) Collapse motion always follows this sequence: False Gate → Noise Spiral → Destructive Rupture → Dissociation → Rigidity → Failed Re‑Entry → Immobilizing Weight → False Gate This motion is: • inverted • unstable • distorted • self‑reinforcing • phase‑misaligned Collapse motion is the failure physics of Threshold.

  7. Recovery Motion (Re‑Entry Motion) Recovery motion always follows this rule: Shadow Phase → Next Master Phase Examples: • False Gate → Signal • Noise Spiral → Fault • Destructive Rupture → Drift • Dissociation → Anchor • Rigidity → Return • Failed Re‑Entry → Burden • Immobilizing Weight → Gate Recovery is: • forward • minimal • stabilizing • phase‑aligned Recovery is not a reversal — it is a re‑entry.

  8. Motion Vectors Every motion in Threshold has a vector — a direction and a force. There are four global vectors:

  9. Opening Vector Moves toward Gate / False Gate.

  10. Pattern Vector Moves toward Signal / Noise Spiral.

  11. Rupture Vector Moves toward Fault / Destructive Rupture.

  12. Continuity Vector Moves toward Burden / Immobilizing Weight. These vectors determine: • where the system is heading • how fast it’s moving • whether it’s stable or collapsing

  13. Motion States Every system has three motion states: Stable Motion Movement is aligned with the Master Cycle. Stress Motion Movement is accelerating toward collapse. Collapse Motion Movement has flipped into the Shadow Cycle. These states apply to: • environments • roles • triads • sensory channels • narrative arcs Everything.

  14. Motion Triggers Motion is triggered by the seven universal interactions: • Approach → moves toward Gate • Attention → moves toward Signal • Pressure → moves toward Fault • Stillness → moves toward Drift • Grounding → moves toward Anchor • Synthesis → moves toward Return • Memory → moves toward Burden These interactions push the system along the motion path.

  15. Motion Misalignment (Collapse Triggers) Collapse occurs when motion is: • too fast • too slow • misaligned • contradictory • overloaded • under‑supported Examples: • Too much pressure → Destructive Rupture • Too much stillness → Dissociation • Too much grounding → Rigidity • Too much memory → Immobilizing Weight Motion misalignment is the root cause of collapse.

  16. Motion Correction (Recovery Triggers) Recovery occurs when the correct interaction is applied: • False Gate → Attention • Noise Spiral → Pressure • Destructive Rupture → Stillness • Dissociation → Grounding • Rigidity → Synthesis • Failed Re‑Entry → Memory • Immobilizing Weight → Approach Recovery is motion correction.

  17. Motion Purpose Global Motion Logic ensures: • cycles move • collapse is predictable • recovery is actionable • environments feel alive • roles activate cleanly • triads behave consistently • sensory channels shift coherently • narrative arcs follow the same physics It is the movement engine of Threshold.
